# 文献路线：Σ_opt 里的候选（2026-10-31）

本路线只看研究库里的论文，不看 KB 路线，也不看主线的推导，以便三条路线做捕获–再捕获估计。

结果在 [`data/cands_lit.json`](../data/cands_lit.json)，由 [`scripts/sci_lit_route.py`](../scripts/sci_lit_route.py) 生成：

- 关键词筛选由脚本计算；
- 相关性判断和候选记录是读论文后写进脚本的数据，每条都注明论文章节。

## 子系统与判据

**Σ_opt。** 两个训练配置共用数据集、模型、损失、batch 和预算 T，只在优化器设置上不同：

- 类型：SGD、Adam、AdamW、RMSprop、Adagrad，均为 PyTorch 默认实现；
- 设置：学习率、动量（0 或 0.9）、权重衰减（0 到 1e-3）、betas。

问题是哪个配置的最终测试指标更低（10 种子均值）。

**层次。** 按 SAI 定义 §3：

- **K**：只在少数设定上观察到。
- **L**：沿条件轴系统扩展过。
- **S**：从显式前提推出，且每条前提都能脱离所预测的关系单独检验。

只讲渐近收敛或 regret、不涉及有限 T 终点比较的结果，不算 Σ_opt 预测，但可以提供前提。

**映射状态（`mapping` 字段）。**

| 值 | 含义 |
|---|---|
| testable | 能在我们的数据上核对：对 S 是前提，对 K/L 是把结论外推到 Σ_opt 后检验 |
| open | 前提或适用条件要用我们没有的量（如 Hessian、梯度统计），或原文设定与 Σ_opt 相差太远 |
| fails | 前提在 Σ_opt 中已知不成立，Σ_opt 内的声明域为空 |
| n/a | 只提供前提，不作预测 |

**5 条 S 的映射都没有落地。**

- **Saxe、Wilson 构造：前提在 Σ_opt 中不成立。** 两者分别要求深线性网络和特定构造的数据。
- **EoS 稳定阈值：要用不可测的量。** 它需要 λmax，我们的数据里没有。
- **Mandt、Three Factors：部分前提可检验。** “训练已到稳态”能在时间轴上独立检验（固定配置只加步数，看损失是否还降）；高斯噪声、常协方差、二次区域、C=H 这几条不可测。

**按 Σ_opt 的差异类型看文献覆盖：**

| 差异类型 | 文献给出的规则 |
|---|---|
| 只差学习率 | 最多（过渡期、稳定上限、稳态、最优点四类），方向随区间相反 |
| SGD 动量 | L（各自调学习率）与 S（稳态，映射开放） |
| betas | 只有 L（Porian 等） |
| 权重衰减 | 没有排序规则，只有等价或不等价命题 |
| 跨优化器类型 | 只有 K；唯一的 S（Wilson 构造）在 Σ_opt 中不适用 |

## 发现

1. **文献给 Σ_opt 的现成预测多数是 K/L，且来自与 Σ_opt 很远的设定。** 这些设定多是语言模型预训练或 CIFAR 上的长训练，学习率逐个调优并带衰减，只能当作外推待检。
   - 18 条预测里 S 只有 5 条，没有一条的前提已在 Σ_opt 中成立。
   - 能用我们的数据检验前提的 S 只有稳态两条（Mandt、Three Factors），且只能检验其中“已到稳态”一条前提。
2. **文献在同一关系上给出方向相反的两组规则，分界正好是能独立检验的前提。**
   - 过渡期：有效学习率较大者胜（EoS 的附带观察、Kaplan 的累计学习率、Sutskever 的动量）。
   - 稳态：有效学习率较小者胜（Mandt：只有 ε/(μS) 决定稳态，期望超额损失随它线性增长；Three Factors 式 (9)）。
   - 分界是“是否已到稳态”，可在时间轴上检验，不用学习率对比。这与 KB 里“只在饱和以下成立”的写法同向，但文献把饱和改写成了可检验的前提。
3. **时间重标前提有文献依据，也有明确的失效处。**
   - 依据：EoS §3.4 直接展示了“按迭代×η 作图，轨迹重合到 sharpness 达 2/η 为止”。
   - 失效处一：大学习率（稳定阈值）。
   - 失效处二：噪声占主导时，Three Factors §2.1 指出固定 batch 下改 η 也改噪声温度。
   - 失效处三：训练早期梯度变化快（Goyal）。
4. **好几条 K 级排序在短训练时方向相反。** 以下都是长训练末端的结论；Σ_opt 的 T 只有 256–2048 步，不宜直接搬用：
   - AdamW 与 Adam 的曲线前半程重合（AdamW §4.3），Chinchilla 里 Adam 一直领先到约 80% 处；
   - 自适应方法在训练初期更快（Wilson）；
   - 不用 warmup 时初期更快（Kosson）。
5. **跨优化器类型没有可独立检验的桥。**
   - 已有的：Adam 与 Adagrad 的对应（§5）是按构造的等式，Adam 与 RMSprop 的差别（§3）是偏差校正。
   - 缺的：SGD 与自适应方法之间没有任何一篇给出能脱离跨类型比较本身去检验的前提。
6. **研究库的目录层次与 Σ_opt 下的层次不同。** 例如：
   - EoS 在目录里记为 Law（现象），在 Σ_opt 里主要提供一条前提和一条 K 级附带观察；
   - Adam 在目录里记为 Knowledge，但它 §3 的偏差推导是 S 型前提。
