# 让石墨烯研究从自动测量走向可检验的理论

原型已连接微观计算、样品图谱与自主研究。下一步要把数值结果变成经过收敛检验的相界和跨样品预测。首期采用一片普通 AB/Bernal 双层石墨烯，即两层碳原子按特定错位方式堆垛的体系。魔角扭转双层石墨烯作为独立后端保留。当前阶段为纯模拟。

## 同一套样品参数应解释多种观测

我们希望让研究程序提出解释、选择计算条件，再用新数据检验解释。研究流程是“提出解释 → 选择条件 → 微观计算 → 独立复核 → 冻结预测 → 新样品检验”。出现失配后修正模型，再进行新的检验。

最终输出是有适用条件、有误差和有反例的理论图谱。每个候选解释必须同时预测多种观测，不能为每条曲线单独调参。agent 指调用工具、提出并检验解释的研究程序。新预测需要文献与专家审查，才能判断学术原创性。

## 已经从输运代理接到了微观模型

最早的原型用经验公式生成电阻，检验采样、机制比较和新数据验证。现在的计算后端从 Hamiltonian（规定电子能量及其耦合的算符）出发，计算能谱、层电荷和响应。普通双层后端采用四能带模型与受控低能约化，依据 [McCann–Koshino 综述](https://arxiv.org/abs/1205.6953)。

已实际运行的范围包括层电荷屏蔽、双金属栅相互作用核、带间光学响应、固定层势的压缩率、共线自旋／谷平均场及单粒子磁场能级。魔角后端采用 [Bistritzer–MacDonald 连续模型](https://doi.org/10.1073/pnas.1108174108)，已有两谷／自旋、均匀应变、层势、氮化硼质量近似与投影平均场。

结构弛豫、非均匀纹理、微观无序、自旋轨道耦合、声子、电子声子作用、超导配对、接触输运与完整材料整数拓扑仍需开发。“所有项”需要逐项定义模型、近似和验证。未支持项请求会明确失败。

## 同一种材料已经算出 20 组样品的响应

改变介电环境和上栅距离后，我们在每组样品扫描 n（载流子密度）与 D（外加垂直位移场）。20 组样品共计算 500 个点，温度为 20 K。远程 8 个 CPU worker（独立执行数值任务的进程）用时 18.52 秒。

输出包括 U（内部层势差）、采样带隙与固定 U 的压缩率。负采样带隙表示采样能带发生重叠。固定 U 的压缩率表示保持内部层势不变时，密度对化学势的响应。动量网格为 20×24，截断为 0.5 nm⁻¹，网格与截断尚未验收。

**注意：** 能谱和带隙不能直接转换成实测电阻。固定 U 的压缩率也不能直接当作包含屏蔽的量子电容。

## 自洽完成仍需要网格与截断检验

HF（Hartree–Fock，用平均场近似处理电子相互作用）已在另 20 组样品运行。每组有 4 个密度与电场组合，使用六种独立初态并做正反续扫。160 次访问中，156 次完成自洽和候选比较，4 次未解。8 个 worker 用时 451.27 秒。

| 证据 | 已通过的访问数 / 总访问数 |
|---|---:|
| 已计算 | 160 / 160 |
| 自洽完成 | 156 / 160 |
| 候选比较完成 | 156 / 160 |
| 动量网格验收 | 0 / 160 |
| 截断验收 | 0 / 160 |
| 物理相确定 | 0 / 160 |

三个代表性设置已经进行误差检查。自洽精度收紧的最后一对检查通过原定门槛，但网格与截断尚未通过完整验收。魔角设置的动量网格由 3×3 改为 4×4 时，采样带隙仍改变约 9.69 meV。保留能带数的改变会改变参考子空间，需要作为模型敏感性单独报告。

相界需要稳定的序参量、竞争态自由能、数值收敛和边界附近复算。序参量指区分对称性破缺状态的量。外场诱导的层极化需要与自发有序区分。平均场有限温边界还需要涨落检验。

## 十二道测试未显示多 agent 的准确率优势

实际语言模型已接入声明的数值工具。swarm（多个研究程序分工提出解释与批评解释）、单 agent 与常规扫描使用相同初始信息和预算上限。所有策略先冻结轨迹，再由独立 evaluator（使用留出答案评分的程序）检验。

三种策略均判断正确 12/12。每种策略给出 8 个有效预测、2 次拒绝和 2 次保留，均无错误高置信主张。swarm 使用更多求解访问，本轮未观察到准确率或预测增益。

| 策略 | 模型调用 | tokens | 求解访问 | 数值成本单位 |
|---|---:|---:|---:|---:|
| 单 agent | 72 | 1,137,716 | 179 | 277.5 |
| swarm | 72 | 1,157,077 | 230 | 363.0 |
| 常规扫描 | 0 | 0 | 187 | 289.5 |

每题上限为 6 次模型调用、24 次求解、160,000 tokens（语言模型处理的文本单元）和 36 个数值成本单位。成本单位按求解工作量定义，不是货币价格。整轮墙钟 1,197.99 秒，独立评分另记成本。

测试覆盖有限候选模型族的重建、遗漏机制与反驳。预测零误差不代表开放世界原创或实验预测。测试中的费米面连通变化也不等同于热力学相界。

## 共享屏蔽预测在新样品上被反驳

共享屏蔽模型与 0.5 meV 的最大误差门槛先被冻结，再用于四组未参与训练的模拟样品。24 个留出点的均方根误差为 0.2302 meV。一个点超过门槛，最大误差 0.5438 meV，因此该统一假设未通过检验。

逐样品模型增加 36 个校准点后，误差为 0.2229 meV。训练与检验的动量网格和数值源码有变化，当前还不能把失配完全归因于样品差异。原始预测与计算均保留。

## 小任务还没有获得明显的 GPU 加速

FP64（64 位浮点精度）CPU/GPU 对照使用相同的四次新访问、多初态工作负载，无缓存访问。

| 材料后端 | CPU 耗时 / s | GPU 耗时 / s | 最大采样带隙差 / meV |
|---|---:|---:|---:|
| 普通双层石墨烯 | 18.210 | 17.178 | 9.92×10⁻⁶ |
| 魔角扭转后端 | 1.597 | 5.350 | 6.45×10⁻⁸ |

能量一致仍不足以证明近简并候选的序相同。32 位精度出现未解候选，尚未用于科学结果。大网格的 GPU 收益需要重新测量。

样品、控制点、初态和无序种子可以独立分发。计算系统已实现校验缓存、分片、断点续跑、失败记录和固定源码版本。增加算力优先用于收敛及竞争态检查，再提高图谱密度。

## 下一步先确定误差，再确定相界

首期六周是研究规划窗口，具体判据由凝聚态专家确定。当前路径为：

- 固定模型，独立细化动量网格、截断与自洽精度，核对对称性和已知极限。
- 冻结序参量与自由能判据，在边界附近复算，比较多初态和正反扫描。无法区分的区域保留。
- 按文献判据增加有限磁场关联、结构、无序、声子、配对和器件输运，逐项记录近似。
- 加入更难的未见组合与遗漏机制，在相同总预算下评测自主研究方法。
- 用少量实验数据校准样品，冻结多观测量预测，再用新条件或新器件检验。

文献工作已取得 180 篇公开全文。检索、下载和正文判据审读分别计数。论文提及的现象需要映射到器件结构、观测签名与求解器，不能把论文数量当作已覆盖物理相的数量。

## 远期让理论提出可由新实验区分的预测

工艺差异可以编码为样品参数集合：局部应变、层间结构、介电环境、无序与接触。系统先检验哪些变化移动相界、哪些改变竞争态，再寻找可以跨样品预测的最小模型。

拓扑可以统一部分有隙相，完整图景还需要对称性、序参量和多观测量。金属、超导和无序不能只靠一个整数分类。无量纲参数关系需要在未见样品上验证，不能预先要求所有曲线重合。

最终预期是一张可以持续修正的理论地图。每个区域记录支持的机制、数值误差、矛盾证据和下一项判别测量。复杂模拟与真实仪器通过同一观测接口连接。当前尚未开展实验匹配，也没有完整材料相图或新物理发现证据。

验收需要用冻结的同一参数体系预测新器件或新条件，获得多观测量支持，并提供收敛证据、原始数组和独立复算。连接真实仪器还需要明确设备能力、稳定性、扫描历史、操作授权和测量成本。
