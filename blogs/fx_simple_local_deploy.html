1. 开源状态

原作未开源:作者主页与视频简介(BV1L5hd6FEi6)无源码链接,GitHub 无官方仓库。但游戏是纯静态前端—— 单个未混淆的 vanilla JS(app.js 约 109KB)+ styles.css + 一张头像,无自有后端, 因此整套站点可完整镜像本地运行。B 站 toy-sdk(云存档/排行榜/分享)缺失时代码自动降级,核心玩法不受影响。

相关第三方仓库:chentianxiong123/fx-simple-trading-bot(Playwright 自动化逆向,结论与本调查一致: 模拟行情为本地随机游走、存档在 localStorage);zeroa234/kurumi-fx-rogue(另一个久留美同人开源游戏,Godot,与本镜像无关)。

2. 本地部署(已验证)

cd fx-simple-local
python3 -m http.server 8471 --bind 127.0.0.1   # 打开 http://127.0.0.1:8471/index.html

实测:零 console 报错;模拟行情、真实历史数据两模式均可用;真实数据模式从 localhost 直连外部 API 成功(CORS 允许)。 index.html 仅移除 B 站 toy-sdk 与平台埋点,游戏本体原样。

3. 数学 kernel 与数据源

  • 模拟/挑战模式:纯本地合成行情。播种 = 正弦波 + 均匀噪声;每 1.5s 一 tick:正弦漂移 + 均匀噪声(±0.21%)+ 1.8% 概率冲击(±0.95%)+ 内置虚构新闻偏置。无外部请求。
  • 真实/战役模式:ECB 历史日线,源为免费无 key 的 Frankfurter API(api.frankfurter.dev/v1),时间尺度 = 1 帧/交易日。

4. API 接入点

  • 换数据源:改 app.js 约 1092-1142 行 fetchFrankfurter() / parseFrankfurter()(后者把 ECB 各币种换算成 7 个货币对)。
  • bot/agent 接入:账户与持仓全在 localStorage:fx-heartbeat-save-v3(主存档)、fx-settings-v1、fx-achievements-v1、fx-challenge-*;可直读写或经 Playwright 注入。

标的 62 个:游戏 7 对 + 全部 FX 交叉盘/新兴货币 + 金银(GC=F/SI=F)+ 原油 + 7 大股指 + BTC/ETH/SOL。 清单见 data/yahoo/manifest.json。

爬取坑位:Yahoo 对 FX 的 1d+range=max 会降采样成月线,须用 range=20y; XAUUSD=X 无效,金属用期货符号。不可达源(本机网络):Dukascopy tick(TLS 阻断)、stooq(JS 工作量验证)、HistData(DNS 失败)——本机可爬上限为 1 分钟线。
