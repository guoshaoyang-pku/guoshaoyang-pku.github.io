01 总览：实验分组与状态

本登记簿的用途：把散落在多台集群、多个专题报告中的实验结果统一登记，每个实验含最终指标、 关键中间观察（observable）与完整 trajectory 链接，方便追溯"agent 是怎么一步步把分数做上去的"。 后续新增实验按此格式追加。当前状态核对时间：2026-08-26；ophis-gpu 上 mlsbench 队列为空、三个 llm-pretrain agent 已结束；Uni-Mol 仍有训练进程，尚未结算最终分数。
数据口径：同一实验组内的表格可以比较；不同任务的指标、不同数据版本和不同题池不能直接拼成一个总 leaderboard。 tree.db 是 autoresearch 树的当前权威状态；run_report.json、progress_*.json 和旧日报是历史快照。本页把“已核验最终结果”“链路验证结果”“仍需访问远程机器才能回填”的三类信息明确分开。

00 指标词典：如何读下面的表

表格中的箭头是优化方向：↑ 越大越好，↓ 越小越好。不同实验的指标没有统一量纲， 不能把例如 val_loss、SHD、PSNR 排在一张总榜里。下面只解释每个实验组内部的指标含义。
实验组指标含义方向
LLM pretrainingval_loss固定 validation token 上的平均交叉熵；衡量模型对未参与更新的文本的预测误差。↓
wikitext2_ppl / lambada_ppl困惑度（perplexity），约等于 exp(平均 token loss)；越低表示下一 token 预测越好。↓
arc_easyARC-Easy 四选一科学常识题准确率。↑
hellaswag情境续写选择题准确率，测试常识性的情境完成能力。↑
piqa物理常识/日常目标导向选择题准确率。↑
winogrande代词指代消歧准确率，测试语境中的常识推断。↑
TRAIN_METRICS训练步数、train_loss、val_loss、学习率等过程量；不是额外 leaderboard 分数，而是用来诊断训练过程。按量解释
InverseBenchPSNR重建图像与真值之间的峰值信噪比，误差越小通常越高。↑
SSIM结构相似度，比较亮度、对比度和局部结构，通常范围接近 0–1。↑
LPIPS / closure-phase χ²LPIPS 衡量感知特征距离；closure-phase χ² 衡量黑洞干涉观测拟合残差。↓
Uni-MolROC-AUC二分类排序指标：随机抽取一个正例和一个负例时，模型把正例排在前面的概率。↑
Causal / MLSSHD结构汉明距离：预测 DAG 与真实 DAG 在边增、边删、边方向错误上的差异总数；0 是完美。↓
F1预测因果边的 precision 与 recall 的调和平均。↑
PEHE个体处理效应估计误差的均方根，用于 treatment-effect 任务。↓
ECE / AUROC / ARI / R²分别是校准误差、异常排序能力、聚类一致性和回归解释度；ECE 下降，其余三个上升更好。混合
ngram-gapgap = validation loss − training loss（或登记表明确标出的 gap 变体）；因果消融比较 intervention 前后的 gap 变化。通常 ↓
autoresearch judgeraw = 排序正确率；norm = (raw − 0.5)/0.5。norm=0 约等于随机排序，正值优于随机。↑
dsh_scanM给定 D 的全空间 sup 数值逼近；这里关心的是它是否严格低于阈值 4。与 4 比较

02 LLM Pretraining 优化

任务设计：GPT-2 Medium（355M），FineWeb 10B 数据，13,535 iter 固定流水线。 agent 只能改 custom_pretrain.py 里的一个函数（loss → compute_loss， optimizer → 优化器配置，kernel → fused_mlp_forward）。 每个 agent 有 10 次 test 预算，每次 test = 完整 5-8h 训练 + 4 个下游评测。 官方 baseline 是手写论文技巧（label_smoothing / softcap_ce / relu_sq_torch 等）跑完整流程。 关键：baseline 只动单个技巧；agent 是"10 轮 observe→调参→组合"的迭代搜索。

9.2 树探索的中间产物与观测闭环

显式 setting→ 短训 worker→ val_loss + loss curve→ researcher / expansion / perturb→ 新节点
