D3：容量与分辨率的描述量

结论

所有实测结论都限于 n=d=9 的满秩（没有零特征值）的固定线性特征、零初始化和全批量 SGD（每步使用全部样本的梯度下降）。学习率 η=0.5，无动量、无权重衰减。初始损失 L₀=0.5。历史对照的阈值 ε=0.01，即初始损失的 1%；保存曲线另评价 ε=0.001，即 0.1%。这里的“预算”是达到指定阈值所需的更新步数。

  • 匹配目标 Rayleigh 商（一阶谱矩 m₁，即目标加权的平均特征值）仍不能唯一确定预算。同谱 λᵢ=i⁻ᵖ 的配对中，p=1/2 分别为 13/38 与 41/364 步；平谱 p=0 的两目标均为 4 步。参数数、trace（特征值总和）、有效秩（谱的有效维数）、初始损失和初始梯度范数均相同。
  • 再匹配二阶谱矩 m₂（目标加权的特征值平方平均值）和实际第一步损失下降，预算仍不同。p=2 时，共同 m₁=7/55、m₂=1/33、首步下降 0.05984848485，预算为 41/319 步，比为 7.780488。
  • 再匹配插值参数范数（使训练误差为零的参数长度），预算仍不同。p=2 的新配对具有共同 m₁=109/964、m₂=19/964、参数范数平方=3076/241，预算为 68/135 步，比为 1.985294，差为 67 步。前两阶谱矩、初始损失、梯度尺度、首步下降与该范数共同相同，仍不能唯一确定预算。
  • 前三阶谱矩与插值参数范数共同相同，也不能唯一确定预算。p=2 的六模态配对（按特征值分解的六个方向）具有共同 m₁=2173/32653、m₂=3607/620407、m₃=487/620407、参数范数平方=11832487/620407。1% 预算为 103/138 步，比为 1.339806，差为 35 步。
  • 同六模态配对仅把阈值从 1% 收紧到 0.1%，保存曲线预算为 160/322 步，差 162 步、比 2.0125。三个坐标 seed 配对全部达到注册比 ≥1.3。匹配的前三阶谱矩和插值参数范数仍不足以唯一确定该预算；本次没有新增训练。
  • 完整目标加权谱（各特征值及其目标能量比例）的已知递推，与各 cell（单个条件与 seed，即随机种子的执行单元）实测整数步一致。测量验证了上述受控反例；递推公式本身不是新发现。
  • 这些反例推翻了“相应注册标量共同唯一确定预算”的解释。已注册的预算分离预测均通过，尚无已测预测失败。首次 ≥10 草稿在训练前解析审查中改为 ≥8，未作为实验预测评估。
  • 预算不等于永久表示容量。所有注册谱满秩，两个目标均可最终插值。空间频率或相近结构分辨率仍未定义。

Formulation

固定特征平方损失、零初始化、全批量 SGD、无动量和衰减时，已知递推为：

[ L_t=\frac{|X\theta_t-y|^2}{2n},\quad H=\frac{XX^\top}{n},\quad w_i=\frac{(u_i^\top y)^2}{|y|^2},\quad m_k=\sum_iw_i\lambda_i^k,\quad \mu_y=\sum_iw_i\delta_{\lambda_i}. ] [ \frac{L_t}{L_0}=\sum_iw_i(1-\eta\lambda_i)^{2t},\qquad T_\varepsilon(\mu_y,\eta)=\min{t\in\mathbb N_0:L_t/L_0\le\varepsilon},\qquad L_0-L_1=L_0(2\eta m_1-\eta^2m_2),\quad|g_0|^2=2L_0m_1. ] [ m_{-1}=\sum_iw_i/\lambda_i,\qquad |\theta_*|^2=2L_0m_{-1}. ]

第一版描述量为 Tε(μᵧ,η)：给定目标加权谱 μᵧ 与学习率 η，达到初始损失比例 ε 所需的整数步。它同时指定目标、阈值和优化器。已知公式 Σwᵢ(1−ηλᵢ)²ᵗ 用于预测和执行核验。

X 是 n×d 的固定特征矩阵，单位为特征单位。θ 是 d 维参数，单位为目标单位/特征单位。y 是 n 维目标，单位为目标单位。n 是样本数，d 是参数数。

L 是每样本平方损失，单位为目标单位²。t 与 T 是更新步数。ℕ₀ 是非负整数集合。η 是学习率，单位为特征单位⁻²。ε 是损失比例阈值，无量纲。

H 是归一化样本 Gram 矩阵（样本间特征内积组成的矩阵），单位为特征单位²。i 是模态索引。u_i 是 H 的单位特征向量，无量纲。λ_i 是对应特征值，单位为特征单位²。

w_i 是非负目标能量比例，总和为 1，无量纲。δ 表示点质量（集中在一个特征值上的质量）。μ_y 是目标加权谱。k 是矩的阶数。m_k 是 k 阶谱矩，单位为特征单位^(2k)。m₁ 是目标 Rayleigh 商。

g₀ 是初始参数梯度，单位为目标单位×特征单位。m₋₁ 是目标加权逆谱矩，单位为特征单位⁻²。θ* 是满秩模型的唯一插值参数，其范数平方单位为目标单位²/特征单位²。只有 L₀=0.5 时，该范数平方的数值等于 m₋₁。本算例采用无量纲特征和目标。

解析审查给出支持集（非零权重所在模态集合）的下界。匹配前两阶谱矩和插值参数范数时，两个支持集的并集若只有四个或更少的不同正特征值，就无法构造非平凡配对；五模态构造可行。再匹配三阶矩时，并集至少需要六个不同正模态，两个目标各有三个非零模态。这些是代数结论，不登记为新测量。

完整目标加权谱的预测与实测整数步一致。下列通过率和误差只描述注册条件，不是跨数据概率。全部条件为 development（可迭代的开发条件），未测试封存 OOD（事前封存的分布外条件）。

每个 p 含 3 个同 seed（随机种子）配对。seed 只是参数坐标旋转的数值检查。共 6 个谱×目标条件、18 cell、9 配对，无置信区间、无删失。P2 的平谱两目标均 4 步与 P3 的 p=1 ≥2.5、p=2 ≥8 均通过。P1 的谱曲线最大误差为 1.665335e−15，配对描述量最大差为 4.440892e−16，也通过。

seed 只检查参数坐标旋转，不是独立数据重复。各对照无置信区间（CI），无删失（未达到阈值的截断记录）。高阶矩与慢模态（小特征值对应的方向）能量仍共同改变，尚不能独立归因。不能把跨对照预算比的变化解释为新增控制的因果效应。

结论只取同 p 内的配对，跨 p 的 trace 不同。未测试架构轴、learned features（训练中变化的特征）、泛化或空间分辨率。不能外推为通用容量定律。

失败与反例

原合同关于梯度范数的措辞不准确。早期合同称初始梯度范数未固定；本线性模型中 ||g₀||²=(||y||²/n)×Rayleigh。初始损失与 Rayleigh 商相同会自动匹配初始参数梯度范数，保存数据复算已确认。单矩配对未匹配实际第一步损失下降。双矩配对已匹配这一量，仍未匹配目标参数范数。跨 p 的 trace 不同，结论只取同 p 内配对。

尚无已测预测失败。首次 ≥10 草稿经训练前纯解析审查改为 ≥8，它不是已测失败预测。三个已注册预算分离对照均通过，新增三阶矩匹配对照也通过。

预算分离保留了竞争解释。B 的慢模态 λ₉ 能量为 0.5164108619，A 不含该模态。二阶矩及第一步下降匹配没有消除预算差。目标参数范数和高阶谱矩也随权重改变，不能把差异独立归因于慢模态质量。

范数匹配后，高阶矩与慢模态能量仍共同改变。A 的 λ₉ 能量为 6561/123392，B 为 0。m₃ 分别为 367/39042 与 271/61696，仍未匹配。三阶矩匹配后，四阶及更高矩与最慢模态能量仍共同改变，解释尚未分开。

不能把预算比从 7.780488 降到 1.985294 独立归因于新增范数控制，因为共同 m₁、m₂ 也改变。比值进一步为 1.339806，但共同 m₁、m₂ 及参数范数也与旧对照不同。不能把跨对照比值变化因果归于三阶矩控制。

数值预测不是盲发现。解析端点来自训练前已知递推，实测验证的是受控反例。恢复时已见一个旧成功端点，属于非盲恢复验证。

0.1% 数值预测来自已见 1% 端点的粗略外推。评价前没有读取新阈值端点；整条来源曲线早已保存，因此不能称为盲发现或封存 OOD。比值从 1.339806 变为 2.0125 只描述同两条目标曲线在两个指定阈值下的变化。它不确定连续阈值上的规律，也不独立识别高阶矩或慢模态能量的作用。

特征构造时有矩阵乘法警告，根因未确定。保存数组均为有限值，18/18 cell 的标量结构/Gram/损失/终点残差复算通过，最大 Gram 误差 6.661338e−16；未发现保存结果受影响的证据。

新源码使用逐元素构造与 einsum（按索引求和的张量运算），新执行未出现旧矩阵乘法警告。旧警告根因仍未确定。
