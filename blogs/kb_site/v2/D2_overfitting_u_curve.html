D2：风险最低点与早停

结论

相同 n/σ² 不保证风险最低点折叠，即这些最低点步数不能全部落在两倍范围内。以下测得结果限于四维对称 Gaussian（高斯）输入、目标 x₀+0.5x₀x₁、宽度 128 的冻结 ReLU 特征（激活取输入与零的较大值）。线性输出层从零开始，用全批量梯度下降（GD）优化平方损失，学习率 η=0.3，无动量。风险指无噪声审计标签上的条件期望均方误差，n 是训练样本数，σ² 是训练标签噪声方差。

相同 n/σ² 不能保证风险最低点步数相差不超过两倍。n=32/64/128、噪声方差 σ²=0.25/0.5/1/2/4、训练样本归一化下，只有 40/44 配对满足该要求，推翻了“全部折叠”的预测。用另两个样本量拟合幂律（最低点步数与 n/σ² 的幂次关系），再预测留出样本量，57/60 在两倍内，达到至少 48/60 的判据。粗略预测通过不等于逐 seed（随机种子）折叠成立。

共享 population 标签归一化（按分布均值和均方根归一化）未消除反例。n32/σ²=0.25 与 n64/σ²=0.5 的 seed414 最低点从 64/180 步变为 62/201 步，比值从 2.8125 变为 3.24194。固定各自数据、再把噪声方差减半为 0.125/0.25 后，最低点为 87/324 步，比值 3.724138 仍超过两倍。样本标签归一化差异不足以单独解释该反例，降噪也未恢复严格折叠。

n32、seed412 的 population 条件中，仅将 σ² 从 0.125 降为 0.0625，终点减最低风险从 0.051388874041238874 降为 0.02215220201337556。后者低于 0.05，支持事前区间 [0.01,0.04]，但不满足原操作性 U 型判据（内部最低点且终点回升至少 0.05）。最低点仍在内部，从 313 步延后至 461 步，晚期风险仍回升。阈值未通过不能解释成 U 型形状完全消失。

n32、seed413 的同一 population 条件中，σ² 从 0.125 降为 0.0625，终点减最低风险从 0.058105292352594984 降为 0.014188114079254938。新差值低于事前区间 [0.015,0.045]，推翻了该区间预测；也低于 0.05。最低点从 230 延后至 433 步，仍在内部，风险回升仍为正。

Formulation

固定特征、零初始化线性输出层、全批量 GD 与平方损失下，条件期望风险按以下已知解析式计算。风险递推与 population 矩不作为新发现。

[ K=\Phi\Phi^\top/n=V\operatorname{diag}(\lambda_j)V^\top,\quad q_j=1-2\eta\lambda_j,\quad f_j(t)=\begin{cases}(1-q_j^t)/\lambda_j,&\lambda_j\ne0,\2\eta t,&\lambda_j=0,\end{cases} ] [ A_t=\Phi^\top V\operatorname{diag}(f_j(t))V^\top/n,\quad R(t)=|\Phi_a A_t y-y_a|2^2/m+\sigma^2|\Phi_a A_t|_F^2/m,\quad t=\min\operatorname{argmin}{t\in{0,\ldots,16384}}R(t). ] [ y^{\rm train}=(g-\mu_n)/s_n,\quad y^{\rm pop}=g/\sqrt{1.25},\quad g(x)=x_0+0.5x_0x_1,\quad E[g]=0,\quad E[g^2]=1.25. ] [ R(t;s)=B(t)+sN(t),\quad t(s)=\min\operatorname{argmin}{t\in{0,\ldots,T}}R(t;s), ] [ \Delta_T(s)=B(T)-B(t(s))+s[N(T)-N(t_(s))],\quad U_{.05}(s)=\mathbf 1{0<t_*(s)<T\;\land\;\Delta_T(s)\ge .05}. ]

n 和 m=2048 是训练与风险审计样本数，单位为行。Φ、Φₐ 是含常数 bias（偏置）列的固定特征矩阵。K 是训练 Gram 矩阵（训练特征两两内积除以 n），V 的列为其特征向量，λⱼ 为对应特征值。η=0.3 是学习率，qⱼ 是每步收缩因子，fⱼ(t) 是累计响应，j 是特征模态索引。Aₜ 把训练标签映射为第 t 步输出层参数。y、yₐ 是 clean（无噪声）训练与审计标签。σ² 是归一化标签单位下的独立训练噪声方差。R 的单位为标签平方，t、t* 的单位为更新步。标签与特征无量纲；diag 表示对角矩阵，⊤ 表示转置，‖·‖₂ 是欧氏范数，F 下标表示矩阵所有元素平方和的平方根。

g 是原始目标，x₀、x₁ 是独立标准 Gaussian 输入坐标。μₙ、sₙ 是原始训练目标的均值与中心化均方根（RMS）。train/pop 上标表示训练样本与分布归一化，E 表示分布期望。B(t) 是无噪声 GD 的 clean 审计均方误差（MSE），单位为标签平方。N(t) 是单位训练噪声方差的审计响应，保存数组名为 variance_unit，单位为风险除以标签方差。s=σ² 是噪声方差；T=16384 是窗口终点，单位为更新步。t*(s) 是该方差下首个全局最低点；Δ_T 是终点减最低风险，单位为标签平方。U₍.05₎ 是取 0 或 1 的操作性判据，𝟙 表示条件成立时取 1，0.05 的单位为标签平方。

经验式为 log(t)=a+b log(n/σ²)。a 是截距，b 是斜率，log 表示自然对数；拟合使用以更新步计的 t 和归一化标签单位下的 σ²。它是本组条件的经验预测，不是解析定律。

成立程度

严格折叠失败，留出预测达到原判据。原 15 个实验条件（recipe）各有四 seed，共 60 cell（一个条件与一个 seed 的执行单元）。最低点均在 8–555 步内部，全部满足终点风险比最低点至少高 0.05。相同 n/σ² 的 40/44 配对落在 [0.5,2]；11 个 recipe 配对组各有四次重复，不能当作 44 个独立 recipe。每次用另两个 n 的 40 cell 拟合，留出 n32/64/128 各通过 19/20，共 57/60。三个留出样本量拟合的 (a,b) 为 (-0.33541,1.05557)、(0.09033,0.96928)、(-0.39273,1.09019)；三个失败预测的倍数误差为 2.286/2.099/2.571。

归一化对照仍只有 3/4 配对在两倍内。等 n/σ²=128 时，seed414 为 201/62=3.24194，满足事前预测 (2,4]，两端均为内部最低点。四 seed 的 population 比值范围为 1.00543–3.24194，log₂（以 2 为底的对数）比值范围为 0.0078195–1.6968554。归一化干预对比值的 log₂ 改变量范围为 −0.1190926–1.0780025。8 个新 cell 的最低点为 62–201 步，全部满足原 0.05 U 型判据。这是一组 recipe 配对、四个 seed 重复。

噪声减半后，等 n/σ²=256 的四 seed 配对仍只有 3/4 达标，seed414 为 324/87=3.724138。8/8 最低点延后 1.403226–2.298611 倍，范围为 87–383 步。全部满足原 U 型判据，终点风险上升 0.051388874–0.177381316。仅 seed414 注册了 (2,4] 的科学预测，其余 seed 为描述结果。该数值事前已由保存的 development 曲线（可据已见结果选择条件的开发验证曲线）算出。实际 GD 是受控复核，不是盲发现。

n32、seed412 的更低噪声评价为一个配对、一个 seed。n32、seed412 在 s=0.125 时 Δ=0.051388874041238874≥0.05，在 s=0.0625 时 Δ=0.02215220201337556<0.05；两者最低点仍在内部。最低点延后 1.472843450 倍。新差值由独立复算核对至 6.19e−15，不给连续噪声临界值，也不给跨 seed 失败比例。噪声方差线性缩放方差项，最低点却随之重选；该配对不能支持终点差值的精确线性缩放。

预指定 seed413 的新配对同样未达到 0.05，但区间预测失败。差值 0.014188114079254938 低于事前下界 0.015，偏差为 −0.000811885920745061；独立差值误差仅 6.467049e−15。最低点延后 1.882608695652174 倍。两个指定 seed412/413 的阈值失败只描述这两条曲线，不给跨 seed 概率；两者都有内部最优点和正回升。

全部条件为 development，没有封存 OOD（事前封存的分布外条件）。最低点是 oracle（使用已知无噪声标签得到的参照最优点），依赖指定解析函数的 clean train/audit（训练/审计）标签。幂律使用其他 development 条件的最低点，不能称为普适标度律或 train-only（只用训练标签）的早停方法。未建立不用 test（测试）标签的早停信号。不外推 learned hidden（参与训练的隐藏层）、Adam（自适应优化器）、小批量、CE（交叉熵损失）、其他宽度或无限训练最优步数。

方法与条件

所有比较沿用冻结特征与有限整数步窗口。输入为 d4（输入维度为四）对称 Gaussian，目标为 x₀+0.5x₀x₁。冻结 ReLU 的 width128/scale 0.03 表示宽度与权重尺度。训练特征居中并按总 RMS 归一化，head（线性输出层）含 bias 且从零初始化。全批量 GD 使用 η=0.3/mom0/nodecay（无动量、无权重衰减）及 float64（双精度浮点数）。逐整数步 0..16384 计算期望 clean-risk（无噪声审计风险）。原扫描为 n32/64/128×σ²0.25/0.5/1/2/4、seed411–414。跨 n 保持 W（特征权重）的 seed，但原始输入分别抽取。经验谱（样本 Gram 矩阵的特征值）与目标投影（目标在特征模态上的分量）均可变化。

归一化对照只改变每个 n/seed 内的 clean 标签归一化。它使用 n32/0.25 与 n64/0.5 的原始输入、W、特征和 epsilon（标准化噪声向量），不重抽数据。噪声方差固定在归一化标签单位。mean（均值）与 RMS 联合改变，未分别识别两者作用，也没有固定原始标签单位的信噪比。

失败与反例

“全部折叠”的预测被四个反例推翻。seed414 在 n32/0.25、n64/0.5、n128/1 时 t* 为 64、180、176 步；seed412 在 n64/0.25 与 n128/0.5 时为 390、160 步；seed413 在 n64/2 与 n128/4 时为 20、47 步。前两个反例共享 n32 结果，不是独立重复。

幂律仍有三个失败预测，倍数误差为 2.286/2.099/2.571。斜率 b 为 1.05557/0.96928/1.09019。零反例的严格折叠与容许 20% 失败的粗略预测可以分别失败与通过，不能用 57/60 的通过结果撤销 40/44 的失败结果。

共享归一化和降噪后，seed414 仍超过两倍。共享归一化使其比值从 2.8125 变为 3.24194；随后噪声减半使最低点从 62/201 步变为 87/324 步，跨 n 比值从 3.241935 变为 3.724138。不同条件的最低点延后幅度仍不同。输入抽样、经验谱与目标在特征上的投影仍是竞争解释。

“降噪后仍达到 0.05”在 n32、seed412、σ²=0.0625 的有限窗口条件不成立：终点差值 0.022152202，阈值余量为 −0.027847798。该条件仍有内部最低点和风险回升。事前预测的是阈值未通过，且得到支持；这不是事前区间预测失败。噪声减弱使终点风险比最低风险下降更多，原操作性 U 型判据失效只说明回升幅度未达到阈值。

seed413 的差值区间 [0.015,0.045] 被推翻。实测 0.014188114079254938 低于下界；不能因同一预测中“低于 0.05”的方向符合结果，就把整个 P1 写成支持。原 .05 操作性 U 型判据同样失败，保留内部最低点与正回升。

执行失败保留为执行失败，不算科学反驳。原执行因预注册提交受阻而未训练，随后恢复；噪声减半准备因临时脚本写出工作区而失效，没有新实测数字或 KB claim（知识库短结论），也没有执行独立实际 GD。原 matmul（矩阵乘法）警告的底层原因未定。归一化分析曾因 NumPy 布尔值不能直接写 JSON 而失败；固定源码和原错误保留，单独入口只把 NumPy scalar（标量）转为 Python scalar，未改风险公式或预测。

未决问题

输入抽样、目标投影与经验谱的独立作用尚未区分。共享标签归一化与噪声减半后仍有反例，现有对照不足以独立归因。

两个指定 seed 的低噪声评价未给出跨 seed 概率。下一小问题可只换为预指定 n32、seed411；其旧 0.125 差值为 0.1773813164971647。复用保存分解评价 0.0625，检验是否仍达到 0.05。先注册新数值区间、来源 hash（内容指纹）与源码，再作零新训练的曲线算术。未评价条件不先算新端点后称盲预测，不据两个噪声点推断连续临界值。
