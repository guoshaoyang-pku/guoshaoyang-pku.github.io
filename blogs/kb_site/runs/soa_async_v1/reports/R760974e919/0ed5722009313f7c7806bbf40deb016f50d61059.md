## Competing explanations and boundaries
Epochs alone, batch noise, target composition/distractors, architecture-dependent fitting/calibration and optimizer trajectories compete. Falling train CE with rising test CE supports generalization; calibration changing CE but not accuracy supports confidence contribution; removing irrelevant inputs at fixed rule tests distractors. Endpoint test CE distinguishes none alone. Function-space progress requires saved logits or trajectories, not Delta.
Solver harmful default is presently a scope/use error: transferring separate heterogeneous shallow/smooth/LN associations and nominal Delta into one architecture law.
