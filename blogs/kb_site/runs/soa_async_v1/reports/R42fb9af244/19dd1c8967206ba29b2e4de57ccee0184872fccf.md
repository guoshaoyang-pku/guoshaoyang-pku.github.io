# Conditional SAME-model MSE Phases: Curvature Rule Fails an Offset Challenge

## Finding
A universal low-rate rule and a universal max-log-Delta rule both fail. A preregistered curvature-based late-sign forecast succeeds on four fresh selected targets, including a held-out-training dataset, but fails by observed mean on a high-offset nested target. Its paired interval includes zero, so this is a failed empirical forecast, not decisive evidence that the population effect reverses. The defensible consolidation is a recipe-gated, target- and budget-conditioned phase map with an unresolved state, not a mechanism law or pooled tendency. No clusters were merged.

## Definitions and Controls
D(T,b)=mean test MSE(.001)-mean test MSE(3e-5); negative means high wins. For each target and comparison set, define H when a paired percentile-bootstrap 95% interval lies below zero, L when above zero, and ? otherwise. These are descriptive uncertainty states, not simultaneous significance decisions or inferred physical phases. Transitions need not be single or irreversible; early and late signs are separate predictions.

Fixed recipe: two active inputs, uniform [0,1], 256 train/256 test points, plain d3w256 default-init MLP, LeakyReLU(.01), LN[1,0,1], plain executed MSE, AdamW(.9,.999), wd1e-5. Main batch16; batch32 is a separately gated intervention. Target nonlinear type, offset, initialization, width, LN, batch and optimizer remain gates. Target/split vary jointly across datasets. Delta=lr*T is nominal, not observed update motion.

All fresh model.py, train.py and loss.py files are respectively byte-identical across rates/datasets/batches. Seeds0–9 are paired RNG seeds; the runner seeds before model construction and draws minibatches with the same RNG. Runtime initial tensors and batch hashes were not saved. Batch-size changes do not preserve identical minibatch streams. Inherited inactive lambda metadata is 1.0 for 6fea20 and .001 for c7715a; executed loss.py is identical unregularized squared-error mean. An initial metadata assertion failed and was corrected by executed-code verification, not retraining.

This phase model is operational and falsifiable: conditional endpoint surface D(target,T,rate pair,batch|recipe), uncertainty-aware state and potentially recurrent transitions. It quantitatively reproduces data but does not predict arbitrary new targets from descriptors; H_C is rejected as a deterministic observed-sign rule. No post-hoc “large-offset exception” is promoted to a law. Offset, type and split are confounded.

A strong extreme-pair H state does not imply unique optimal .001: at 2048 .001/.0003 ratios .827828 for 183f73 and .919070 for 6fea20, paired intervals span zero, both 7/10 high wins. ## Mechanisms, Boundaries and Next Tests
Actual runner artifacts expose paired seed endpoints and per-step test curves, but NOT initial/train MSE, gradients, parameter/output updates, checkpoints or optimizer-state forks. train.py computes minibatch loss but does not save it. No function/update motion was invented from target derivatives or loss curves. Schedule and target-centering/scaling interventions remain unsupported by the documented contract; recorded once, no repeated probes and no surrogate experiments.

Competing explanations remain fitting speed, trajectory/basin choice, rate-scaled AdamW shrinkage, late stochastic optimization and train/test generalization. Between-seed SD is not late temporal jitter; test loss fluctuation is not output-motion RMS. Underfit predicts worse low-rate train AND test fit; generalization predicts high-rate train improves while test worsens; reversible jitter predicts actual late output motion and joint residual improvement after a checkpoint-matched downshift. These distinguishing tests cannot be run with this interface.

A next not-yet-controlled allowed target 8b90ea has nested cos plus polynomial/tanh terms. Register only an exploratory H_C replication forecast: .001 beats 3e-5 at2048 under the exact recipe; any observed mean reversal fails that forecast. After the present failure it is not an accepted-law prediction. More informative future interventions would center/scale a59d63 without changing points, and fork matched checkpoints for constant versus downshift rate with saved train/test/output motion. Both are unexecuted and require runner support.

No transfer to other offsets, initializations, widths, LN patterns, activations, batches, optimizer defaults, dimensions or T>2048 is established. K1115's univariate zeroLN Adam and K1117's three-input residual SiLU Adam remain distinct; they constrain blanket max-Delta/low-rate rules but cannot populate this recipe's phase surface. Preserve K1001/K1012 progress below saturation and K1072 risk-with-counterexamples. No mechanism law or claim merger is warranted.
