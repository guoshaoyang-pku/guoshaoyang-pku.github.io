# Target-dependent optimizer reversals near calibrated parity
## Conclusion
Target-dependent gradients and Adagrad memory are plausible contributors, but their causal role is **not identified** by the available measurements. Controlled endpoint experiments reject a universal adaptive-over-SGD preference and a universal conservative-Adagrad preference. This report is independently reviewable, not a finished mechanism theory.

## Mechanism and Phase Map
For MSE, g_j=2*mean[(f-y)*d f/d theta_j]. Target centering changes the output-bias gradient and residual projections; scaling y alone is not scaling the entire residual when f is nonzero. Target dependence therefore has a mathematical route, but actual gradient RMS was not measured.
Adagrad uses S_j(t)=S_j(0)+sum g_j(s)^2 and update -eta*g_j(t)/(sqrt(S_j(t))+epsilon), absent lr_decay. Uniformly scaling an entire gradient history by positive c cancels in the update only when initial accumulator and epsilon are negligible. Late shrinking gradients with a large retained S produce shrinking updates; accumulated memory does NOT guarantee sustained output motion or lower test loss.
| Phase | Evidence | Distinguishing test |
|---|---|---|
|Low proxy progress|More failures and worse endpoints in several r.25 cells|Measure layerwise gradient RMS and actual updates; separate baseline-fitting failure from divergence|
|Near proxy parity|Matched mean orderings depend on target/budget; some CIs overlap zero|Paired centering/scaling with fixed inputs/init/batches; measure gradients, output motion and cumulative coordinate-effective lr|
|Higher ratio, longer budget|Grid higher-Adagrad-rate gains coexist with XOR16 conservative advantage|Retain versus reset accumulator at a fixed checkpoint; compare optimizer schedules and train/test trajectories|
Overshoot, persistent noise, gradient-history anisotropy, momentum lag, architecture interaction and generalization remain competing explanations. Falling train loss with rising test loss would support overfitting; test curves alone cannot establish it. Resetting Adagrad state changes more than a nominal learning rate and needs paired reset controls.
## Blocked Tests, Boundaries and Reproduction
Target-transform override was explicitly rejected: dataset.target_scale is unsupported; only model./optimizer./loss./budget. overrides are allowed. Direct diagnostic regeneration/training attempt failed while importing torch: sandbox blocked ctypes.dlopen. Available artifacts contain seed endpoints and test-loss curves, not train loss, actual gradient RMS, accumulator, cumulative effective lr or output motion. No such measurements are fabricated. Centering/scaling resilience and accumulator causality remain unresolved.
Needed next: an authorized instrumented runner exposing exact allowed point tensors, paired target transforms (train-only mean for centering), gradient/update/state traces, fixed-rate duration controls, accumulator retention/reset, schedules, and independent split/seed cohorts. Predict uniform gradient-history scaling is resilient before epsilon dominates, late gradient shrinkage after large accumulation is not; adaptive invariance can fail when target transforms alter curvature, gradient signs or coordinate histories.
No extrapolation to arbitrary architecture, batch, feature count, decay, loss, target scale or tuned optimizer optimum. Stronger decay is not universally negligible; larger Adagrad rates are neither universally superior nor universally inferior.
