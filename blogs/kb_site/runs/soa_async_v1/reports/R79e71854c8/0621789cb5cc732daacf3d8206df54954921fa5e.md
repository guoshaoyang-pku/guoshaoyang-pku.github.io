## Identification and limitations
Request actual gradient RMS, accumulator, cumulative effective learning rate, output motion, and train/test curves. If runner cannot expose these or legally transform targets, endpoint controls cannot establish target-gradient or accumulator causality; report blocked tests explicitly. Centering/scaling predictions precede any such experiments. Exact focal recipe contrasts remain distinct from isolated optimizer/rate controls. Count datasets separately from dependent budget/rate cells; use paired seed CIs only if seed outcomes/pairing are available, otherwise conservative covariance bounds and missingness. Cache reuse is not replication.

## Competing explanations and phase map
Low proxy progress: insufficient optimization competes with gradient suppression. Near parity: target-dependent geometry, momentum lag, coordinate normalization and generalization compete. High ratio/long budget: cumulative Adagrad attenuation, overshoot, noise and overfitting compete. Distinguish by measured updates, accumulator reset versus retention, target transforms and train/test divergence. No blanket adaptive-over-SGD or conservative-Adagrad preference is proposed. Predictions fail if matched near-parity ordering stays invariant across all tested conditions, if higher-rate short-budget Adagrad worsens, or if measured adaptive output motion scales just as strongly as SGD under paired target transforms.
