## Mechanism Limits
Gradient diagnostics were rejected. Curves contain only test CE, sample counts and batch size; returned outcomes additionally expose final accuracy. Actual data gradients, decay/parameter norms, train CE, margins, logits and checkpoints were unavailable.

Decay-start and head-exclusion capability fields were accepted as metadata but ignored by generated optimizer code. Both probes implemented ordinary base RMSprop, not the requested interventions. They are excluded from causal evidence and factorial counts; provenance is saved.

Positive scalar temperature preserves argmax. Each binary error contributes at least log2 CE, so easy/T2048/wd.001 calibrated mean CE is bounded below by **.00071075/.00047383**, above the zero-decay floors. This analytic bound rules out complete temperature rescue, but is not an executed calibration experiment.

Small-decay CE changes without observed errors support altered confidence, not uniform margin shrinkage or an unchanged boundary between sampled points. Adaptive moments, hidden representations, cancellation and boundary movement remain competing explanations.

## Ratio Tests and Solver Guidance
Define layerwise `r_l=wd*||w_l||/||g_data,l||` before L2 addition; distinguish minibatch from full-training gradients. Raw norm ratios are not Adam update dominance: preconditioning, momentum and gradient/decay angle also matter. AdamW shrinkage acts outside gradient moments.

Next, implement authenticated logging and predict a held-back allowed setting before training, comparing a pilot-fitted ratio predictor against a preregistered wd-only baseline. From a shared converged checkpoint, branch with identical moments/minibatches into no/head-only/hidden-only/all decay. Stable decisions plus temperature-recoverable CE favor margin suppression; changed errors and irreducible loss favor boundary effects.

Condition first: these exact d3w48/plainSiLU/all3LN/lr.001/betas(.9,.95)/T2048 one-turn controls show tiny CE penalties at small coupled decay and changed decisions at.001. Report absolute CE and errors. Do not infer universal safe wd, turns thresholds, or incomparable-recipe winners.
