## Mechanism tests: completed limits, not fabricated diagnostics
The public diagnostics.gradient_norms override was rejected. Archived curves.npz contains only per-seed test-CE curves, sample counts and batch size. train.py returns final accuracy but no train CE, gradients, parameter norms, margin quantiles, logits, optimizer states or checkpoints. Hence actual layerwise r, margin suppression, gradient/decay alignment and a measured-r forecast were not computed.
Capability probes optimizer.decay_start_step and optimizer.decay_scope were accepted as spec fields but ignored by generated optimizer.py. They produced ordinary base RMSprop .003/wd.001, not the fixed Adam network/interventions. Exclude both ten-seed probes from causal evidence and factorial counts. Unsupported spec metadata is not an implemented intervention. No materialized input tensors/checkpoints are exposed in the allowed artifacts; inventing a new generator would not reproduce these matched splits.
A positive scalar temperature preserves argmax. For binary errors its CE contribution is at least log2, so calibrated mean CE at easy/T2048/wd.001 is bounded below by error*log2:.00071075/.00047383, far above the zero-decay floors. This analytic bound uses measured errors; it is not an executed calibration test. It rules out complete temperature rescue at wd.001, but does not quantify recoverable confidence loss.
At smaller decay, CE changes with unchanged held-out error are consistent with altered confidence on observed points, not proof of uniform logit shrinkage or an unchanged boundary between points. Hidden-representation optimization, adaptive moment changes, cancellation and boundary movement remain competing explanations.
## Ratio definition and distinguishable future tests
Define layerwise r_l=wd*||w_l||2/||g_data,l||2 before L2 addition; log minibatch and full-training CE gradients separately, parameter/bias/LN norms, margin quantiles, train/test CE/errors and failures. A raw norm ratio is not Adam update dominance: diagonal preconditioning, momentum and gradient/decay angle must also be logged. For AdamW the same numerator is only a reference; actual shrinkage is lr*wd*w outside gradient moments.
Required next test:implement authenticated logging on these exact allowed materialized splits; fit the ratio predictor only on a pilot cohort, publish its predicted ranking/absolute CE change on a held-back allowed split before training, and compare its out-of-sample error with a preregistered wd-only baseline. No r cutoff can be selected from these CE-only results.
From a shared converged wd0 checkpoint, retain identical Adam moments and minibatch stream and branch into no/head-only/hidden-only/all decay. Margin-only suppression predicts falling positive margins with stable decisions and substantial training-fitted positive-temperature CE rescue. Changed error/lower-tail negative margins and irreducible calibrated loss predict boundary effects. Apply the same branch budget to controls; do not calibrate on held-out labels.
