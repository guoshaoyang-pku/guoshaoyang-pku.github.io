## Definitions and methods
CE is held-out cross entropy, lower better. Depth counts width-to-width hidden blocks after input projection. Block is act(Linear(LN(x))+x) for residual, act(Linear(LN(x))) for plain. Terminal LN precedes final hidden Linear/activation, not the head.
Exact recipes: E d5 GELU residual LN[1,0,0,1,1]; B d3 LeakyReLU(.01) residual LN[1,1,0]; C d3 LeakyReLU(.01) plain LN[1,1,1]. Default initialization, width256, input8/output2, CE; shared SGD lr.0003 momentum.9 wd.0001, T256 b64.
Preregistered primary datasets: lexicographically first three allowed XOR8 IDs xorcls_02a6e3, xorcls_10e86c, xorcls_12238f, chosen without examining recipe outcomes. Each has train1024/test2048 standard-normal features, two active XOR features, differing fixed seeds and active coordinates. Ten training seeds per recipe; report means, SDs, numerical pair margins, paired seed counts and failures. Seeds are conditional training replications, not independent datasets. Cached measurements are not new replications.
Prediction before experiments: E<B<C in each primary dataset mean, with residual B beating C in at least 7/10 paired seeds per dataset. This is a testable transfer hypothesis, not a deterministic LN or skip rule.
Boundary test planned separately: same E/B/C architecture/SGD/wd/T at input4,width24,b16 on xorcls_063fc1 and xorcls_4779bd. Prediction: B<C persists but E<B may fail; no pooled conclusion with XOR8. Width, input dimension and batch change jointly, so any reversal does not identify which causes it.
