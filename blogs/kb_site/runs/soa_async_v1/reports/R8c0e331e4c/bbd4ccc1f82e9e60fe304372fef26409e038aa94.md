# Full-recipe B versus C: preregistration and evidence audit
## Question and provisional conclusion
q_e285d5 establishes an ordinal B-over-C result on one five-input mixed symbolic target and fixed split, not an optimizer law. Its actual B is already deep: plain d4/w128 GELU LN[T,T,F,T], default initialization, SGD lr .0003 momentum .9 wd0. C is residual d5/w96 GELU LN[F,T,T,T,T], default initialization, AdamW lr .001 betas(.9,.95) wd.0001. Both T1024/b32,32768 samples, plain MSE. Depth counts blocks between input and output projections. “Shallower generic B” is insufficient: widths, residuals, normalization positions, optimizer, betas and decay all change.

## Preregistered new controls
Use three allowed comparable five-input symbolic datasets: mvar_05883d (mixed nested oscillatory/polynomial,+.5), mvar_06497c (mixed nested oscillatory/polynomial,-1.5), mvar_0f2210 (polynomial,+1). No exact architecture cells exist in the frozen lab.
Directional forecasts before training: C has lower mean MSE atT256 on all three; atT1024 B beats C on05883d and06497c, whereas C remains better on polynomial0f2210. These are uncertain falsifiable full-recipe predictions, not mechanisms. Primary test is B/C endpoint mean ratio at each budget. Report signed differences, per-seed paired effects if supplied, failure/exclusion/cache status and dispersion. A long B preference requires both mixed targets to support it; any C win is a counterexample. Neither 2/2 nor 3/3 would establish population generality.
Targets/splits are crossed only as complete dataset instances: offset,variance,function shape and split cannot be causally separated. No target normalization or offset intervention. Compute target summary moments from allowed data if accessible; otherwise label numerical proxies, never fabricated split statistics.

## Mechanisms and boundaries
Endpoints do not identify late precision, oscillatory fitting, overshoot,jitter or generalization. Undertraining,trajectory dependence,representation,decay and optimizer state are competing explanations. A discriminating future test crosses architecture and optimizer with matched seeds and logs train/test curves,function-update RMS and gradients; same-state downshift forks distinguish reversible noise from persistent trajectory effects. Full-recipe controls answer recipe transfer, not architecture-versus-optimizer causality.
No universal multivariate maximum-Delta or conservative-Delta rule is proposed. New target/split/init/batch/architecture transfer remains unmeasured.
