## Recipes
S: input Linear(2,192), ReLU, two width192 blocks ReLU(x+Linear(norm(x))) with LN [true,false], output Linear(192,2), PyTorch default Linear initialization. RMSprop lr .001, weight_decay 1e-5, other PyTorch defaults.

Depth counts blocks excluding input/head: S has four Linear layers; D has seven. Authentication of the experiment implementation is required before causal component experiments.
