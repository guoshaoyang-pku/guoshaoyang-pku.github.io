# KB setting

下一版设置如下。异步调度、恢复、版本隔离与发布已在隔离工作区验证；现场目录仍受访问限制，尚未接入运行。

| 项目 | 设置 |
|---|---|
| 题池 | 四源固定 seed 抽样，按共同数据实例及 dataflip 配对整组划分；新 release 待读取当前输入后生成。 |
| 计分 | 选择题正确得 1；排序逆序 0/1/2/3 得 1/0.75/0.5/0.25，其余 0。 |
| 解题 | gpt-6.1-sol；默认完整简洁 KB，science 按需展开；每题冻结版本，回答后揭示答案。 |
| Batch | 下一版设为 30。旧 soa_v4 最后核验的配置为 40，保存记录的首批实际为 30。 |
| 研究与总结 | 40 分钟为轮次等待上限；超时原任务继续，标记为下一轮成员；研究工具调用不限 14 次。 |
| 恢复与写入 | 任务停止后恢复原会话和 checkpoint；报告与修改提案持久保存，主进程应用；commit 保留发起和应用轮次。 |
| Science | 一个报告可解释多条 claim，含竞争解释、可区分预测和未决问题；下一轮使用最新已保存版本，无 ready 门槛。 |
| 公网 | 沿用实验页展示完整 KB、报告、代码与日志；内容变化后最多每 30 分钟 push 一次，核验线上字节。 |
