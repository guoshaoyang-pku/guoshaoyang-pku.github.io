## Explanations, Predictions and Boundaries
Accumulating Adagrad state, rate-induced trajectory differences, late optimization precision, instability and generalization compete. Endpoint test MSE does not identify annealing or overfitting; neither training loss nor updates/accumulators were measured. q's original split is not an allowed lab dataset and was not retrained. Analogue failures do not overturn its gold.
Preregistered but unrun next tests: if overfitting explains q-like reversals, training MSE should keep falling while test MSE rises; if persistent update noise explains them, a high-to-low AdamW schedule should improve long endpoints at equal samples; if accumulator memory is decisive, resetting versus preserving Adagrad state at continuation should change the advantage. These require paired fresh-seed controls, training/test trajectories and measured updates; reset results alone would still need trajectory controls.
No universal Delta ceiling, low-rate rule, optimizer preference, width law or continuous optimum follows. Budget changes T and samples together at fixed batch; their separate effects remain unidentified. Transfer to new splits, seed cohorts, inactive-feature sparsity, other model shapes/LN masks, batch sizes, optimizer eps/state defaults and T beyond1024 remains open. Exact same-split/config recomputations falsifying the recorded inequalities would challenge these measurements.
