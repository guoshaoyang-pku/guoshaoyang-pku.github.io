11.10 Bottom-up 验证：阴性对照、table RMSProp 与 + Muon 的 Norm/Loss 时间对齐

目的

11.9 在 current-shell 正例上发现 gate/table norm 的增长与 gap 的发生基本同步。 这里把同一验证下沉到三个 nanogpt_original 架构 setting（seed 42，1000 step，单 shard tr1）： B.0 阴性对照（table AdamW、matrix AdamW，无 target gap）、 B.1 table RMSProp（table optimizer=RMSProp，matrix=AdamW）、 B.2 + Muon（table AdamW，matrix=Muon）。 对每个 setting 画出 gate norm / table content RMS（raw value RMS）/ gated value RMS（实际注入幅度）随 step 的曲线， 叠加 epoch 边界与 gap onset，并按 n-gram context 命中频次（bigram-context、trigram-context 各一套 bin， fig14 即 trigram-context）拆分 train/val/gap loss。判据：norm 增长的时点是否与该 setting 的 gap 时点对齐； B.0 作为阴性对照，用来检验"没有 target gap 时 norm 增长是否也缺席/不与任何 gap 峰值对齐"。
