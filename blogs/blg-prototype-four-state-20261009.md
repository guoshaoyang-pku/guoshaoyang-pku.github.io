# 四种候选态竞争，哪一条边界会改变电子排列？

实际复算的候选能量重建了自旋与层极化的竞争，连续变化和一阶跳变可以逐点查看。

材料是一片 AB/Bernal 双层石墨烯。固定填充 ν=0（零能能级一半填满）、零温，使用零能 Landau 能级投影（保留强磁场下 0、1 两种低能轨道）与均匀平均场。

## 电场偏向某一层，磁场偏向某个自旋方向

[返回综述](blg-literature-review-20261009.html#prototype-section) · [打开屏蔽 prototype](blg-prototype-screening-20261009.html)

电场让电子更偏向一层。Zeeman 能量（磁场对自旋方向的能量偏好）让自旋更趋于同向。相互作用同时约束这两种变化。我们按 Kharitonov 的四候选态理论，在 10,201 个控制点比较能量。点击图，或用下方滑杆选择已计算点，可以查看谁的能量最低、是否接近交叉。

## 能量相等，可能是连续端点，也可能是不同排列的交叉

横轴是层电场能 εV，纵轴是自旋 Zeeman 能 εZ，均除以 |u⊥|（一个相互作用能标）。另外固定 uz/|u⊥|=2，即第二个各向异性作用能标。坐标是无量纲比值，需要屏蔽和相互作用校准后才能映射到实际电场与磁场。

<!--four-state-cut-->

铁磁 F 中自旋同向。倾斜反铁磁 CAF 中两层自旋的横向分量相反，同时向磁场倾斜。部分层极化 PLP 保留层间相干且有层占据偏好。完全层极化 FLP 则达到这个模型允许的最大层占据偏好。

虚线位置是 CAF 接到 F、PLP 接到 FLP 的连续端点，两个名称在此描述同一极限状态。实线位置是 CAF 与 PLP、F 与 FLP 的一阶候选交叉，电子排列可以跳变。CSV 中的等能点因此不能一律视作新的相。

## 理论与倾斜场实验共享竞争图景，数值坐标需要校准

[Kharitonov 2012](https://doi.org/10.1103/PhysRevLett.109.046803) 的理论提出：在固定垂直磁场下，提高总磁场可增强自旋能量，推动倾斜反铁磁走向铁磁。层电场则推动层极化。这给出了检验电子排列的实验路径。

![固定垂直磁场的倾斜场实验分区](blg-review-assets-20261009/maher2013-fig4.png)

**Maher 等，1212.3846v2，图 4，p4。** 实验固定 ν=0、垂直场 1.75 T，改变总磁场与位移场，区分低场绝缘、高场导电和层极化区域。CAF/F 是结合理论的解释，实验没有唯一分开 PLP 与 FLP。原图的部分渐变是作者示意。来源：[Nature Physics 2013](https://doi.org/10.1038/nphys2528)。

这个 prototype 将候选身份连回能量、排列和可测控制。当前没有计算边缘电流或器件电阻，没有拟合 Maher 的相界。因此理论图与实验图保留各自坐标，尚不能定量叠加。

<p>定义 v=εV/|u⊥|、z=εZ/|u⊥|，候选能量以 |u⊥| 归一化。采用 u⊥/|u⊥|=−1、uz/|u⊥|=2，公式来自 1105.5386v2，p3：</p>
<ul><li>F：E=−2z。</li><li>CAF：E=−2−z²/2，只在 z≤2 这一倾斜分支有效。</li><li>PLP：E=−1−v²/3，只在 v≤3 这一部分极化分支有效。</li><li>FLP：E=2−2v。</li></ul>
<p>图中所有值读取保存的数组，滑杆吸附到已有网格点。归一化自旋与层响应分别按 −½∂E/∂z、−½∂E/∂v 得到，它们不是单位为磁矩或电荷的直接实验读数。切线图中的空白区表示相应分支超出有效端点。</p>
