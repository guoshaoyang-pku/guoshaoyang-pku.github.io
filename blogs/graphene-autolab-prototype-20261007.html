让石墨烯研究从自动测量走向可检验的理论

原型已连接微观计算、样品图谱与自主研究，下一步要把数值结果变成经过收敛检验的相界和跨样品预测。

  • 对象 一片普通双层石墨烯
  • 阶段 纯模拟
  • 控制 密度 / 电场 / 温度

同一套样品参数应解释多种观测

我们希望让研究程序提出解释、选择计算条件，再用新数据检验解释。最终输出是有适用条件、有误差和有反例的理论图谱。每个候选解释必须同时预测多种观测，不能为每条曲线单独调参。

首期采用 AB/Bernal（两层碳原子按特定错位方式堆垛）双层石墨烯。魔角扭转双层石墨烯由两层之间的小转角形成长周期结构，作为独立后端保留。两种材料共享研究工具，各自使用对应的物理模型。

怎样判断一次自主研究有价值

agent（调用工具、提出并检验解释的研究程序）需要给出最小模型、参数来源、适用域、收敛证据和冻结预测。新预测还需要文献与专家审查，才能判断是否具有学术原创性。仅恢复模拟器预设规律不能构成新物理发现。

已经从输运代理接到了微观模型

最早的原型用经验公式生成电阻，检验采样、机制比较和新数据验证。现在的计算后端从 Hamiltonian（规定电子能量及其耦合的算符）出发，计算能谱、层电荷和响应。普通双层石墨烯采用四能带模型，参数和低能约化依据 McCann–Koshino 综述。

四能带描述层内运动和层间耦合。层电荷与栅极电静力相互反馈。已计算能谱、态密度、层势差、固定层势的压缩率与带间光学响应，并接入多初态平均场求解。

同一种材料已经算出 20 组样品的响应

我们改变介电环境和上栅距离，在每组样品上扫描 n（载流子密度）与 D（外加垂直位移场）。20 组样品共计算 500 个点，温度为 20 K。远程 8 个 CPU worker 完成这轮计算用时 18.52 秒。worker 指独立执行数值任务的进程。

下面的 U（内部层势差）来自电子屏蔽后的自洽电静力。采样带隙是有限动量网格上的谱估计，负值表示采样能带发生重叠。固定 U 的压缩率表示保持内部层势不变时，密度对化学势的响应。

注意：如果微观响应尚未计算器件输运，能谱和带隙不能直接转换成实测电阻。固定 U 的压缩率也不能直接当作包含屏蔽的量子电容。

自洽完成仍需要网格与截断检验

HF（Hartree–Fock，用平均场近似处理电子相互作用）已在另 20 组样品上运行。每组有 4 个密度与电场组合，使用六种独立初态并做正反续扫。160 次访问中，156 次完成自洽和候选比较，4 次未解。8 个 worker 用时 451.27 秒。

自洽表示迭代找到了满足声明容差的候选解。网格、动量截断和竞争态仍会改变结果。三个代表性设置已经检查这些误差，但尚未通过完整网格与截断验收。因此，当前保存的是候选响应图谱，物理相分类仍未确定。

相界需要怎样的证据

相界需要稳定的序参量、竞争态自由能、数值收敛和边界附近复算。序参量是区分对称性破缺状态的量。外场诱导的层极化需要与自发有序区分。候选初态的名称不能直接成为相名。

现有三个设置收紧自洽精度后，最后一对检查通过原定容差。魔角设置的动量网格由 3×3 改为 4×4 时，采样带隙仍改变约 9.69 meV。保留能带数的改变会改变参考子空间，需要作为模型敏感性单独报告。

平均场的有限温度边界还需要涨落检验。找到最低的已知候选自由能，也不能证明精确多体基态。

十二道测试未显示多 agent 的准确率优势

实际语言模型已接入声明的数值工具。swarm（多个研究程序分工提出解释与批评解释）与单 agent、常规扫描使用相同初始信息和预算上限。所有策略先冻结轨迹，再由独立 evaluator（使用留出答案评分的程序）评测。

三种策略均判断正确 12/12。各自给出 8 个有效预测、2 次拒绝和 2 次保留，均无错误高置信主张。swarm 用了更多求解访问，本轮没有观察到准确率或预测增益。

共享屏蔽预测在新样品上被反驳

我们先冻结共享屏蔽模型和 0.5 meV 的最大误差门槛，再计算四组未参与训练的样品。24 个留出点的均方根误差为 0.2302 meV。一个点超过门槛，最大误差为 0.5438 meV，因此该统一假设未通过检验。

这个检验保留了提出统一解释、冻结预测、接受反例的完整过程。逐样品模型增加 36 个校准点后，误差为 0.2229 meV。训练与检验的动量网格和数值源码有变化，因此当前还不能把失配完全归因于样品差异。

小任务还没有获得明显的 GPU 加速

CPU 与 GPU 已在相同的四次新访问、多初态工作负载上比较。FP64（64 位浮点精度）用于这轮基准。普通双层后端的 GPU 收益有限，当前小规模魔角后端使用 CPU 更快。

CPU 与 GPU 的最大采样带隙差分别约为 9.92×10⁻⁶ meV 和 6.45×10⁻⁸ meV。能量一致仍不足以证明近简并候选的序相同。32 位精度出现未解候选，尚未用于科学结果。大网格的 GPU 收益需要重新测量。

大量 CPU 怎样转化为研究进展

样品、控制点、初态和无序种子可以独立分发。跨节点优先扩大任务吞吐量。计算系统已经实现内容校验缓存、分片、断点续跑和失败记录。长任务固定源码版本，避免计算期间改变实现。

对较重的相互作用计算，GPU 需要批量矩阵和张量运算，并尽量让数据留在显存。数值精度、内存和相界误差必须与速度一起记录。增加算力优先用于收敛和竞争态检查，再提高图谱密度。

下一步先确定误差，再确定相界

首期六周是研究规划窗口，具体判据由凝聚态专家确定。现在最急的是困难区域的网格、截断和竞争态细化。每个物理扩展需要实际验证，并更新覆盖表。

  1. 确定误差固定模型后独立细化动量网格、截断和自洽精度，核对对称性及已知极限。保存失败和近简并候选。
  2. 确定平均场边界冻结序参量与自由能判据，在边界附近复算，比较正反扫描和多种初态。无法区分的区域继续保留。
  3. 增加机制与观测按文献判据接入有限磁场关联、结构、无序、声子、配对和器件输运。逐项登记近似与适用域。
  4. 检验研究方法加入更难的未见组合和遗漏机制，在相同总预算下比较多 agent、单 agent 和数值扫描。先冻结，再评分。
  5. 连接实验用少量数据校准样品，再冻结多观测量预测。用新控制条件或新器件检验，并设计能区分解释的测量。

文献工作已经取得 180 篇公开全文。检索、下载和正文判据审读分别计数。文章提及的现象需要映射到器件结构、观测签名和求解器，不能把论文数量当作已覆盖物理相的数量。

远期让理论提出可由新实验区分的预测

工艺差异可以编码为样品参数集合：局部应变、层间结构、介电环境、无序和接触。系统先检验哪些变化只是移动相界，哪些会产生不同的竞争态，再寻找能够跨样品预测的最小模型。

拓扑可以统一部分有隙相，但完整图景还需要对称性、序参量和多观测量。金属、超导和无序不能只靠一个整数分类。无量纲参数的统一关系需要在未见样品上验证，不能预先要求所有曲线重合。

最终预期是一张可以持续修正的理论地图：每个区域记录支持的机制、数值误差、相互矛盾的证据和下一项判别测量。复杂模拟与真实仪器通过同一观测接口连接。当前尚未开展实验匹配，也没有完整材料相图或新物理发现证据。

远景怎样验收

用冻结的同一参数体系预测新器件或新控制切片，获得多观测量支持。用竞争模型给出不同预测并设计判别实验。提供收敛结果、原始数组和独立复算。完整图谱需要声明模型、参数域、分辨率和未知区域。

未来系统会主动建议实验。连接真实仪器还需要明确设备能力、稳定性、扫描历史、操作授权和实际测量成本。
