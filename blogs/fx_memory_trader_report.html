FX 日线隐式记忆交易模型:实验报告

2026-10-09 · 项目 fx-memory-trader · 数据:ECB 参考汇率日线 1999-02 → 2026-10(7,089 天 × 12 货币对)· 成本:单边 1bp · 集群:ophis-gpu 8×H200

1. 问题与记忆设计

检验两类"有限区域隐式记忆"能否在日线 FX 上学到扣成本后仍成立的样本外 edge:

  • lesson-token 上下文记忆:每段情节经验(市场路径 + 自身已实现盈亏,即"自己的教训")经 cross-attention 压缩为 8 个不可解释的连续 token,放入策略的短上下文;内容只由"对未来应变有用"的梯度塑造(对应 in-context learning as implicit gradient descent、gist tokens / ICAE 式学习压缩、RL² 元学习目标)。
  • KDA 有限区域:Kimi-Delta-Attention 式通道门控 delta 规则,把整条历史逐 token 写进定长 d_v×d_k fast-weight 状态,q 联想读出——同一思想的在线写入版本。

v2 另加:周/季/年日历 inductive bias(sin/cos 5/63/252d + 月初/月末/季末 dummy)、参与门控 g_t∈[0,1](应激特征+自身近期盈亏)、黑天鹅窗口(2008 GFC、2015 瑞郎、2020 COVID、2022 战争与金边危机)在损失中降权 0.2。

2. 评估协议

train ≤2016 / val 2017-2020(早期停止、阈值调参)/ dev 2021-01→2024-09(开发报告)/ heldout 密封段 2024-10-01→2026-10-07(515 天):冻结权重后仅评估一次,不因它改任何东西; 此后接纸面实盘日志自然延伸。仓位只用 t 及以前信息、赚 t+1,边界无标签泄漏;唯一泄漏通道(迭代选择)由密封纪律堵死。

4. 结论

  • 日线 FX 上没有任何变体拿出样本外 edge:train Sharpe 1.3-1.6 → val/dev/heldout 全负,纯过拟合 + 高换手空转(turnover 500-700/年)。
  • 门控从未学会收手(gate flat 0%):黑天鹅降权同时删掉了"撞进去要挨打"的避让梯度——设计取舍失误,已记录在 runs.log。
  • 数据支持的可部署策略退化为操作者规则本身:平时近空仓、named 应激 regime 才出手("可以憋几年")。
  • 密封 heldout 协议生效:它把 val/dev 已暗示的坏消息变成了一次性、不可迭代的最终裁决。

5. 下一步(按优先级)

  1. 换手正则/最少持仓期,治空转;
  2. 门控改有监督(规则化 risk-off 标签)或恢复 swan 全权重只降权信号拟合项;
  3. 头层加向零仓位的收缩先验(spike-and-slab);
  4. 换粒度:1m/5m/1h 缓存(242 万行)已备好,日内 SNR 更高;
  5. 周频再平衡 + 利差 carry 代理。
