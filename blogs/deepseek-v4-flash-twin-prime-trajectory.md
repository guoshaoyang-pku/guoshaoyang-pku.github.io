## 1. 数学背景：246 纪录的完整逻辑链

### 1.1 判据（Polymath8b, arXiv:1407.4897）

无条件（Bombieri–Vinogradov，θ = 1/2）下，若

$$M_{k,\varepsilon} > 4 \qquad (m=1, \theta=1/2)$$

则 DHL[k,2] 成立，即存在无穷多 n 使 n + h₁, …, n + h_k 中至少两个为素数（h 为任意可容许 k 元组），从而

$$H_1 \le H(k) := \min\{\max h - \min h : h \text{ 可容许 } k\text{-tuple}\}$$

其中 M_{k,ε} = sup_F [Σᵢ J_{i,1−ε}(F) / I(F)]，F 支撑在 ε-扩大单纯形 (1+ε)R_k 上（定理 3.12，ε-扩大单纯形版本）。

**可容许**：k 个互异整数，对每个素数 p ≤ k，模 p 的剩余类不覆盖全部 p 个类（p > k 自动满足）。

### 1.2 纪录链

| 年份 | 纪录 | 关键进展 |
|---|---|---|
| 2013 | 70,000,000 | 张益唐：新素数分布定理（光滑模 MPZ 型）→ k₀ = 3,500,000 |
| 2013 | 4,680 | Polymath8：分布常数改进 → k₀ = 632 |
| 2013 | 600 | Maynard–Tao 多维筛：k₀ 暴降到 105 |
| 2014 | **246** | Polymath8b：M 泛函变分优化 + ε-扩大单纯形 → k₀ = 50；H(50) = 246 |

关键数值（Polymath8b 严格计算）：M_{50,1/25} > **4.0043**——k=50 首次压线过 4（裕量 0.1%）。**k < 50 的 M_{k,ε} 数值从未被发布**（我们的文献核实确认了这一空白）。

## 2. 元组侧：H(k) 的完全自足证明

### 2.1 搜索算法（自研，C 实现）

对固定 (k, d) 判定 [0,d] 内是否存在可容许 k 元组：

- **归约**：平移不变性 ⟹ WLOG 含 0；最小直径 ⟹ WLOG 含 d；模 2 ⟹ 全偶。候选 = {0, d} ∪ 偶数。
- **DFS + 频数剪枝**：维护每个素数 p ≤ k 的已覆盖剩余类位掩码；剪枝条件为"已覆盖类位置数 + 频次最高的 budget 个新类位置数 ≥ 还需选择的个数"（budget = p−1−已覆盖类数）。这是本项目少数需要从第一性原理推导的组件（初版剪枝有数学错误，经手算反例修正）。
- **完备性**：对每个偶数 d < H(k) 逐点证明 UNSAT（搜索彻底性由剪枝的数学正确性保证）；在 d = H(k) 处给出显式见证元组。

## 4. M_{k,ε} 泛函：严格判定工具链（本项目方法论上最重要的部分）

### 4.1 符号积分框架（自研，精确有理数）

函数族：$F(t) = (1+\varepsilon-\sum t)^r \cdot g(p_1,\dots,p_m)$，$p_a = \sum_i t_i^a$ 为幂和，g 为幂和单项式 $\prod p_a^{m_a}$ 的线性组合（基 = 度数 ≤ D 的幂和多重集，大小 p(0)+…+p(D)）。

所有积分闭式化（Dirichlet 型），关键恒等式：

$$\int_{(1+\varepsilon)R_k} (1+\varepsilon-\textstyle\sum t)^s\, p_\gamma\, dt = (1+\varepsilon)^{k+|\gamma|+s}\,\frac{s!\, H_k(\gamma)}{(k+s+|\gamma|)!}$$

其中 $H_k(\gamma)$ = 槽位（带标签）划分为坐标组的组合计数 $\sum_{\text{partitions}} \frac{k!}{(k-g)!}\prod_{\text{groups}}(\text{group sum})!$，用 DP 精确计算。J₁ 侧同理（Beta 函数 + 1−ε 缩放的 Dirichlet）。

**已发现的数学现象**：k 个变量上，part 数 > k 的幂和基线性相关（Newton/基本对称多项式恒等式）——例如 5 变量上 p₁⁶ 可由 ≤5-part 的幂和多项式表出。这曾一度被误判为 bug，实为正确的代数事实（精确核向量验证）。

### 4.2 严格判定：LDLᵀ 惯性定理（无近似）

**判定命题**：M_{k,ε} > 4 ⟺ J₁ − (4/k)·I 存在正特征值 ⟺ 其精确有理数 LDLᵀ 分解的枢轴含正号（对称矩阵惯性定理）。所有运算为 Fraction（任意精度整数），**无浮点近似**。

过程中发现并修复的关键 bug：矩阵构建中 `int/int` 混入 float 污染（曾导致假"正特征值"判定）；修复后 J₁ 全 Fraction、对称差精确为 0。

### 4.3 严格结果（族内，D=8）

有理数二分（LDLᵀ 惯性 + 二分）给出族内 λ_max 的**严格区间**（宽度 < 10⁻¹⁰）：

| k | ε | 族内 M（D=8，严格） | 参考：真实值（外部） |
|---|---|---|---|
| 46 | 1/25 | **3.6518799** | ≈ 3.96（渐近标定） |
| 49 | 1/25 | **3.6970517** | ≈ 3.99–4.00（渐近标定） |
| 50 | 1/25 | **3.7111478** | 4.0043（Polymath8b） |

- D=8、D=10 的 LDLᵀ 判定均严格证明"族内 M < 4"（k=46/49/50）。
- D=10 的族内严格值（二分）与 D=12 的判定在更大规模上运行中（大整数运算，单点数小时）。
- 坐标下降给出的精确下界（3.21–3.24）劣于二分（说明优化器非瓶颈，二分是完备的）。

**局限（必须声明）**：有限多项式族（度数 ≤ D）内 M < 4 不能推出全空间 M_{k,ε} < 4（真实 sup 更大；k=50 的族内 3.71 vs 真实 4.0043 即为例证）。若某 D 处族内 > 4 出现，则**自动成为真实 M > 4 的完整证明**（下界单调）；但我们的证据表明真实值 < 4，故该路径大概率不会触发。

### 4.4 解析上界（论文方法的数值优化）

Polymath8b 的 Prop（mkeps）与 Remark：

$$M_{k,\varepsilon} \le \frac{k}{k-1}\log(2k-1)$$

$$M_{k,\varepsilon} \le \frac{k}{a(k-1)}\log\left(k + \frac{(a(1+\varepsilon)-1)(k-1)}{1-a(1-\varepsilon)}\right),\quad \frac{1}{1+\varepsilon}<a<\frac{1}{1-\varepsilon}$$

对 a 数值最优：

- **k=44, ε=1/50：上界 3.948 < 4 ✅（完整证明该点）**
- **k=46, ε=1/50：上界 3.991 < 4 ✅（完整证明该点）**
- k=46, ε=1/25：上界 4.070 > 4（**缺口 1.75%**）——全空间"∀ε 排除"未闭合

我们尝试过双参数/三参数权重族（G_i = c/(u+v·t_i)、c/(u+v·s′+w·t_i) 型）改进上界，数值结果不佳或推导待完善——**1.75% 缺口仍是开放问题**（需要新数学或 Polymath 级区间算术工程）。

### 4.5 启发式证据（非严格，但方向一致）

- **渐近标定**：以论文实测 M₅₄ ≥ 4.00238 标定 M_k ≈ log k − 2loglog k + 2.7805，加 ε 增益（由 M₅₀,₁/₂₅ = 4.0043 标定 ≈ 0.04）——交叉点精确复现在 **k = 50**；M_{46,1/25} ≈ 3.96，M_{49,1/25} ≈ 3.995。
- 若真实 M₅₄ 略高于 4.00238（下界），k=49 的真实值可能非常接近 4——**这是本项目唯一未能排除的"超越"场景**（但族内收敛趋势不支持）。

## 6. 方法与历史纪录方法的对比（重要）

- **历史纪录**（70,000,000 → 246）的每一步：解析数论新定理定 k₀（张益唐分布定理 → Maynard 筛 → Polymath 变分优化），元组搜索只是**最后一步的"存在性上界"**（当时张益唐甚至用朴素构造，未用最小元组）。
- **本项目的元组工作**：穷举证明**最小性下界**（H(k) 确切值）——比纪录所需更强，但**方向相反**：它不能产生新的更小上界。
- **核心结论**：元组侧已到底（H(46)=216、H(50)=246 均最小）；任何更小的纪录 d 都要求解析侧突破（M_{46,ε}>4 或 M_{49,ε}>4，即 k₀ 从 50 降到 46/49），而所有严格与启发式证据都指向 M_{k<50,ε} < 4。
