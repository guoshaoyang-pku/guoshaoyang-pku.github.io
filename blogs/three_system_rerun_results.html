06 Trace 叙事：四个系统的执行过程

数据来源：dsh session trace（session.jsonl.zstd）、codex CLI 日志、 官方 interactive 的 leaderboard.csv test 记录。四个系统（interactive / codex / dsh 完整版 / dsh 极简+pro）地位平等，各用其过程数据重建「指标随时间/步骤演化 + 每点修改说明」。
同任务对比（causal-observational-linear-non-gaussian）：四个系统都在这个任务上做到 或接近 SHD=0，但过程与代价完全不同。interactive 只有 4 次 test()、中途改崩后回退； codex 用 20+ 个实验系统搜索 BIC 剪枝变体；dsh 完整版提出 SAIL-LiNGAM 三阶段法；极简+pro 通过可观测中间量（SHD/F1/NaN 诊断）迭代逼近。见下方各节。

6.1 interactive（官方）· non-gaussian —— 4 次 test 内的挣扎与回退

test#1≈baseline 水平：SHD=2/3/6（ER30/ER50/SF100）， 即 DirectLiNGAM + adaptive Lasso 的水平，没有任何超越。
test#2修改后崩盘：SHD=268/791/3900——一次大改 直接毁掉结果（可能引入错误回归或 NaN）。
test#3回退：回到 test#1 的方法，恢复 SHD=2/3/6。
submit最终提交 test#4：SHD=2/3/6，与 baseline 持平。
局限无过程 trace：官方 interactive 只记录每次 test() 的分数（写 leaderboard），不保存中间工具调用，无法重建「为什么改崩」。 只有 3 次 test 预算（本配置），一次失败就几乎无法挽回。

6.2 codex · non-gaussian —— 20+ 实验系统搜索 BIC 剪枝

exp#1baseline：DirectLiNGAM + BIC，SHD=4/4/38。
exp#2-4三个变体全达到 SHD=0：bic+t4 （BIC + t-统计量阈值 4.0 剪枝）、ebic1（eBIC penalty=log n+2·log d）、 bic+c0.3（BIC + 系数 |β|≥0.3 剪枝）。关键洞察：baseline 的假边是「弱系数」， 用阈值/更严惩罚就能去掉。
exp#5消融踩坑：试 cstd（噪声缩放 floor） 变体，部分 seed 崩到 SHD=213（过剪枝），放弃该方向。
exp#6最终：选 bic+c0.3s（noise-scaled effect-size floor），官方评测 ER30 SHD≈3.6 / ER50 SHD=0 / SF100 SHD≈0.6。
特点探索最深但无预算：codex 可以无限跑实验， 但也因此没有「收敛」压力，最终提交反而不如中间态（曾达到全 0）。且无自动结算。

6.3 dsh 完整版（flash）· non-gaussian（SAIL-LiNGAM）+ ml-calibration（BRSC）

non-gaussianSAIL-LiNGAM（Significance-Augmented Iterative LiNGAM）： 诊断发现 baseline 的 DirectLiNGAM+adaptive Lasso recall=1.0 但保留 2-6 条假边（SHD 2/3/6）。 两个 novel 贡献：① Order polish——bubble 局部交换修正序错误（SF100 SHD 3→2）； ② Two-stage sparse pruning——adaptive-Lasso(BIC) 保 recall + OLS refit + Holm-Bonferroni FWER(α=0.001) + BIC backward 去假边。最终 ER30/ER50/SF100 全 SHD=0 F1=1.0。
ml-calibrationBRSC（Bounded-Residual Stacked Calibration）： session trace 显示先做 binary calibration（ECE 0.084→0.032）、发现 Monte-Carlo 校准 （0.116→0.008）是最大单项提升，最后打磨为 BRSC 多校准器堆叠。最终 rf-mnist ECE=0.012242。

6.4 dsh 极简+pro · non-gaussian / subgroup / calibration

non-gaussian可观测驱动的调试闭环：baseline adaptive lasso SHD=3（F1 0.994）→ 用 prune tau=3.0/sqrt(n)+min_coef=0.15 在 dev 达 SHD=0 → 写回踩坑（NaN bug，SHD=103）→ 修 _dmi_matrix 对角 NaN 后二次写回 → 官方评测三场景全 SHD=0 / F1=1.0（110 分钟）。
subgroupworst-group ECE 0.349→0.129：baseline beta-only 0.349 → grouped beta + anchor 0.134（观察分箱误差定位「需分组」）→ 消融确认 anchor → multi-seed 鲁棒 → extra7 温度变体 → 官方 worst_group_ece_adult=0.129104。
calibration候选打分 + CV-NLL band 选择：建立 calib_proto 原型，对多候选（temp/isotonic/beta/platt）打分 → 用 2×5 CV 的 pooled NLL 做模型选择， 3% band 内选最强单调校正 → band 1.025→1.03 后选到 conf8_1.0，rf-mnist ECE=0.005467 （比 dsh 完整版 BRSC 的 0.0122 更优）。
共性模式与系统差异：四个系统都遵循「先复现 baseline → 用可观测中间量定位短板 → 定向修改 → 局部验证 → 保留有效改动」的闭环。差异在于：interactive 的 3 次 test 预算太紧且无 trace；codex 探索最深但无收敛压力、无自动结算；dsh 完整版 提出最完整的方法 （SAIL-LiNGAM/BRSC）；极简+pro 用最少的工具集（只有 Bash+编辑器）拿到同等或更优结果 （non-gaussian SHD=0、calibration ECE 0.0055），说明可观测闭环比工具多寡更关键。
