06 Trace 叙事：三个任务的执行过程

数据来源：dsh session trace（session.jsonl.zstd 解压后解析）， 记录 agent 每一步的工具调用与中间结果。下图为「指标随时间演化 + 每个关键点的修改说明」， 完整展示极简+pro 模式如何在有限预算内通过可观测中间量驱动算法改进。

6.1 causal-observational-linear-non-gaussian —— 从 SHD=3 到完美 SHD=0

t≈0–26min探索与 baseline：读任务描述、摸清 LiNGAM 评测脚本与 mlsbench-causal-learn 环境；在 $HOME/tmp_lingam_dev/ 建本地 dev， 复现官方 baseline = adaptive lasso，ER50 SHD=3 / F1=0.994。
t≈26–74min调试循环（可观测驱动）：写 debug_prune.py / debug_lasso.py / debug_er50_fp.py 等，逐项观察 Lasso 坐标下降、剪枝阈值、refit 对 SHD/F1 的影响。发现 prune tau=3.0/sqrt(n) + min_coef=0.15 时 ER30 SHD=0 / F1=1.0（t≈74min）。
t≈74–84min写回踩坑：把 dev 的 custom_algorithm.py 写回 workspace， 但 local_eval 竟然 SHD=103（dev 入口与 workspace 入口不一致）。
t≈84–105min追查 NaN bug：发现 _dmi_matrix 对角是 NaN、 _search_sink 排除 self-pairs、iterative 与 static 排序不一致等问题， 逐项修复 D 矩阵计算与链式回归。
t≈105–110min完美收官：二次写回后 local_eval 三场景全 SHD=0 / F1=1.0；跑官方 run_test.py，ER30/ER50/SF100 全绿，写 RESULT.md。

6.2 ml-subgroup-calibration-shift —— worst-group ECE 从 0.349 → 0.129

t≈0–7min探索：读 score spec（worst_group_ece）、看 baseline （beta calibration）、确认环境无 aif360（改用 sklearn 自带）。
t≈7–10min第一个大胜：baseline beta-only 的 worst-group ECE 只有 0.349；换成 grouped beta calibration + anchor（gbeta_anchor）后降到 0.134—— 观察分箱误差（adult/compas 各组的 ECE、acc、q）定位了「单一 beta 不够，需要分组」。
t≈10–19min消融与变体：sweep 确认 anchor 有用（none=0.134 vs prob_kc50=0.207）；sweep2 试 logit 版（0.141），没更好。
t≈19–22min鲁棒性：multi-seed 验证（seed0=0.125 / seed1=0.121）， 确认方法稳定。
t≈22–30min精调+官方评测：extra7 温度变体把 wg 压到 0.1291； 写回 workspace、清理临时文件，跑官方评测，最终 worst_group_ece_adult=0.129104。

6.3 ml-calibration —— ECE 从 0.084 → 0.0055（BRSC）

t≈0–12min探索与 baseline：读 parser（TRAIN/TEST_METRICS）、 baseline 是普通温度缩放；观察到 raw 模型 ECE（rf-mnist）≈0.084。
t≈12–14min标准校准：binary calibration（Platt/Beta）把 ECE 降到 0.0319；madelon 上 temperature scaling 到 0.0342。
t≈14–41minMC（Monte Carlo）校准：发现 mc 变体把 ECE 0.1157 → 0.0080（rowsum 误差 2e-16），是当时最大单项提升。
t≈41–99min打磨为 BRSC：把多个校准器（temp/beta/spline/MC）做 variance-aware stacking + bounded residual（BRSC），逐数据集核对 TEST_METRICS， 最终 rf-mnist ECE=0.005467（对比 raw 0.084，降 93%）。
共性模式：三个任务都遵循「先复现 baseline → 用可观测中间量（SHD/F1/分箱 ECE/ 残差）定位短板 → 定向修改 → 局部验证 → 保留有效改动」的闭环。极简工具集（只有 Bash+编辑器） 并没有阻碍 agent 完成复杂调试——它把精力集中在 写小实验脚本 + 看输出 这一核心循环上。
