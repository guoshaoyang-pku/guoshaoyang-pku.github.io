视觉语法 v4.1：一种写法覆盖 9 个经典模型

新语法把 CNN、MLP、Transformer 合成一种节点写法。有 torchvision 参考的 6 个模型，参数量全部相等，载入同一份随机权重后输出也一致，其中 ConvNeXt-T 和 EfficientNet-B0 是旧语法写不出的。GoogLeNet 的 JSON 从 238 行降到 45 行。鼠标移到左侧任一行，右侧高亮对应的 JSON。

卷积 池化 / 采样 repeat（参数独立） residual parallel（concat / add / mul） 命名块

JSON






CNN 的节点数和 JSON 行数大幅下降，ViT 多写 4 行换来显式结构





语法只有一条规则：每个节点都写成 {"操作": 值}


根层写 input_shape、act、norm、bias（默认 false）、blocks、forward。任何深度的节点写法都相同，type 字段取消。值的取值范围不写在语法里，由 challenge 自己声明。




操作写法说明


conv_layers[64, 64, "pool", {"out": 256, "k": 1, "act": false}]数组里的整数是一层 conv → norm → act，k 默认 3；可以插入池化或任何节点


conv{"out": 96, "k": 4, "s": 4}单独的卷积，不带 norm 和激活；groups: "dw" 是 depthwise


pool"max"、"global"、{"k": 3, "s": 2, "pad": 1}默认 max 2×2；{"out": [7, 7]} 是自适应池化


residual[...] 或 {"body": [...], "act": true, "shortcut": "none"}形状变化时自动用 1×1 投影；act 是相加之后的激活


parallel{"branches": [[], [...]], "merge": "mul"}merge 是 concat（默认）、add 或 mul；空分支是恒等


repeat{"n": 4, "bottleneck": {...}, "first": {"s": 2}}每次参数独立；first 只改第一次的块参数


blocks 里的名字{"inception": {"a": 64, ...}}定义一次，之后当操作用；块内用 $a 读参数


norm、act{"norm": true}、{"act": "sigmoid"}true 用根层设置，字符串覆盖它


attention、mlp{"attention": 12}、{"mlp": 3072}图像和 token 都能接，所以 CNN 和 Transformer 可以混用


其他patch_embed、upconv、layer_scale、flatten、linear、dropout、head、seq





还差 2 件事才能出题



  
1. 搜索还接不上
challenge 要声明每个字段的取值范围，变异算子也要定义。命名块和 $参数 让一处修改影响多层，这会改变"一步移动"的含义，需要先定规则。

  
2. 训练细节没有表达
stochastic depth、权重初始化和 GoogLeNet 的辅助头都不在语法里。它们不影响参数量，但影响能否复现原始精度。
