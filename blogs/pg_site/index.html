题目

这个项目在做什么

在固定的小算力预算下（单卡训练 2 分钟），找最好的小语言模型结构，并把找到的规律整理成可以复用的知识和可以考 agent 的题。所有分数都在同一个协议下测得，不能直接和官方 Parameter Golf 的成绩比较。
由 tools/pg_site.py 从知识库、报告数据和搜索状态生成。分数都是本项目协议：单张 RTX PRO 5000 训练 120 秒（或 600 秒），看最后 64 步的训练 loss，1024 词表。
