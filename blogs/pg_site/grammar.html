结构不同：PG 语法逐层写，主语法用“默认模块 + 层号覆盖”

PG 设置语言：每层一个对象

{
  "layers": [
    {"type": "own", "mixer": {"type": "conv"}, "mlp": {"type": "swiglu", "mult": 8}},
    {
      "type": "own",
      "mixer": {"type": "attention", "window": "full"},
      "mlp": {"type": "swiglu", "mult": 10}
    },
    {
      "type": "own",
      "mixer": {"type": "attention", "window": "full"},
      "mlp": {"type": "swiglu", "mult": 12}
    }
  ]
}

PG 语言现在也接受主语法形状的“默认 + 覆盖”写法（pg_setting_lang.serialize），两种写法得到同一个 key；字母串 C8 A10 A12 只用于显示。

主语法：每槽一个默认模块，少数层用 layers 覆盖

{
  "layer_loop": {
    "iteration": 3,
    "body": [
      {"type": "attention", "n_heads": 6, "gqa_kvheads": 3},
      {"type": "conv（主语法没有）", "layers": [1]},
      {"type": "mlp", "hidden_dim": 2560, "gated": true},
      {"type": "mlp", "hidden_dim": 2048, "gated": true, "layers": [1]},
      {"type": "mlp", "hidden_dim": 3072, "gated": true, "layers": [3]}
    ]
  }
}

层号从 1 开始；"array(4,4,6)" 表示从第 4 层起每隔 4 层取 6 个。MLP 写绝对隐藏宽度，SwiGLU 写成 gated: true 加全局 act: silu。

主语法有两条互斥的路径，我们的结构两边都要用

主语法里 smear、bigram_hash、rope_dim、output_gate、xsa、execution 只在 PG 路径可用；而 PG 路径要求 body 严格是一项 attention 加一项普通 MLP，不允许层覆盖、GQA 和 gated MLP。我们的前列结构同时用到 n-gram 表、smear、部分 RoPE（PG 路径）和逐层不同混合器、逐层 MLP 宽度、GQA、SwiGLU（普通路径），所以在现在的主语法里没有一条路径能完整写出来。

  1. PG 设置语言已接受“默认模块 + layers 覆盖”写法，字母串只做显示（已做）。
