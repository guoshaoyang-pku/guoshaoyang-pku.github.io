Loss gap：最小模型、具体数据与边界

目前没有在自然语料上观测到稳定的 −1 指数；loss gap 也不普遍正比于方差。单个数据集上的精确对象是采样残差与 learned logits 的内积；跨训练集取期望后才是 residual–response covariance。

结论先行：−1 是 resolved count table 在线性响应下的条件渐近结果，不是自然语言必须满足的定律。配对实验（§3）显示频率–gap 曲线的全部结构都由 n-gram 表产生，backbone 对照臂完全平坦；optimizer 消融（§4）反解出的响应指数 a 全部落在 0 附近而非 1，因此观测斜率是 −1/2 量级 —— 指数由「表如何写入」决定，不由采样方差决定。

1. 最简单、但没有偷换假设的模型

固定一个 context。训练数据集为 D，真实条件分布为 p，经验分布为 p̂_D，模型在该数据集上学到 logits z_D。记采样残差 δ_D=p̂_D−p。

\[ \mathbb{E}[\delta_D]=0,\qquad \operatorname{Cov}(\delta_D)=\frac{\operatorname{diag}(p)-pp^{\mathsf T}}{f},\qquad \sqrt{f}\,\delta_D\overset{\mathcal{D}}{\longrightarrow}\mathcal{N}\!\left(0,\operatorname{diag}(p)-pp^{\mathsf T}\right)\quad(f\to\infty). \]
\[ \begin{aligned} G_D &=\operatorname{CE}(p,q_D)-\operatorname{CE}(\hat p_D,q_D)\\ &=\delta_D^{\mathsf T}\log q_D =\delta_D^{\mathsf T}z_D. \end{aligned} \]
最后一个等号利用 Σδ=0，softmax 的归一化常数严格抵消。

这也精确对应你的写法：对 target distribution 求导有 ∂CE(p,q)/∂p=−log q；这里固定 q_D，并用 δ=p̂−p，所以 CE(p,q_D)−CE(p̂,q_D)=δᵀlog q_D。导数的变量不是模型概率 q。

\[ \mathbb{E}_D[G_D]=\sum_i\operatorname{Cov}_D\!\left(\hat p_{D,i},z_{D,i}\right). \]
这里的期望是：固定同一个真实 context 分布，重复抽取训练数据集 D。它不是“固定一份 corpus，只换模型 seed”。

把 logits 分成无采样残差时的基线 z* 与 learned response u_D=z_D−z*，单次数据集的 realized gap 是

\[ G_D=\underbrace{\delta^{\mathsf T}z^{\star}}_{\text{sampling fluctuation}} +\underbrace{\delta^{\mathsf T}u_D}_{\text{learned response}}. \]
第一项是均值为 0、典型大小 f⁻¹ᐟ² 的 sampling fluctuation；第二项才可能产生系统性的 train optimism / val excess。

若模型响应在当前区域可展开为 z_D=z₀+Aδ+½B[δ,δ]+…，才得到

\[ \mathbb{E}[G]=\operatorname{tr}(A\Sigma) +\frac12\,B:\mathbb{E}\!\left[\delta^{\otimes 3}\right] +\text{higher moments}. \]

所以协方差 Σ 是局部线性响应的首项；三阶、四阶和更高矩并没有被精确式排除。

“分布无偏”不等于“train loss 无偏”

E[p̂_train]=p；独立的 p̂_val 同样满足 E[p̂_val]=p，所以不能说“val 分布有偏”。偏差来自模型 q_D 正是用 p̂_train 拟合的：train loss 因复用同一样本而 optimistic；独立 val loss 对固定 q_D 无偏估计 population CE，但该 population CE 相对最优熵 H(p) 有 estimation excess。在平滑、全支持且大样本的 resolved count table 中：

E[L_train]−H(p)≈−(K−1)/(2f)，E[L_val]−H(p)≈+(K−1)/(2f)，相减才是 (K−1)/f。

低维支撑的真正作用是把有效维数固定为 K−1，并在所有 fp_i≫1 后允许统一 Taylor 展开；它不会让经验分布本身变成有偏估计。你说的“随数据量变化的 bias”更准确地说是拟合同一样本后，对 loss 这个非线性泛函产生的自适应偏差。

2. 为什么指数不一定是 −1

你写的 ΔL≈(∂L/∂p)δp 描述的正是上面的第一项。若偏导被当成与采样无关的常数，则 signed mean 因 E[δp]=0 消失，而典型大小/绝对值为 O(f⁻¹ᐟ²)。一般 K 类分布有

\[ \operatorname{RMS}\!\left(\delta^{\mathsf T}z^{\star}\right) =\sqrt{\frac{(z^{\star})^{\mathsf T}[\operatorname{diag}(p)-pp^{\mathsf T}]z^{\star}}{f}} =\sqrt{\frac{\operatorname{Var}_{Y\sim p}[z^{\star}(Y)]}{f}}. \]
若中心极限定理近似成立，\(\mathbb{E}|\delta^{\mathsf T}z^{\star}|\approx\sqrt{2/\pi}\,\operatorname{RMS}\)。

二元比例残差进一步给出

\[ \begin{aligned} \mathbb{E}|\hat p-p|&\approx\sqrt{\frac{2}{\pi}}\,\sqrt{\frac{p(1-p)}{f}},\\ \mathbb{E}|G_1|&\approx|\operatorname{logit}(p)|\sqrt{\frac{2}{\pi}}\,\sqrt{\frac{p(1-p)}{f}}. \end{aligned} \]
第一式只是分布残差；第二式才是 loss 的一阶项。当 p=1/2 时，比例残差的系数是 1/√(2π)，但 logit(p)=0，loss 的一阶项恰好消失。若把残差定义成 Rademacher mean 2(p̂−1/2)，其绝对值系数才是 √(2/π)。

更一般地，若基线已达到 z*=log p+constant，一阶系数是 √Varp(log p)；均匀 p 时 log p 在 simplex 切空间上为常数，一阶项同样消失。

若二元模型平滑地跟随训练比例，写成 q_D≈p+ρδ，则最小展开是

\[ G_D\approx\operatorname{logit}(p)\,\delta +\frac{\rho}{p(1-p)}\,\delta^2. \]
第一项的 signed mean 为 0、绝对尺度为 f⁻¹ᐟ²；第二项的期望为 ρ/f。p=1/2 时 logit(p)=0，所以一阶随机项恰好消失。

系统性期望 gap 还必须加入“模型如何响应这份残差”。令 u(δ) 为 learned logit response，则 G_response=δu(δ)。若 u(λδ)≈λᵃu(δ)，统一标度为 E[G_response]∝f−(a+1)/2：

线性响应 · a=1

u(δ)=ρδ，则 E[G]=ρE[δ²]∝f⁻¹。这才是方差律。

符号/饱和响应 · a=0

u(δ)=sign(δ)，则 E[G]=E|δ|∝f⁻¹ᐟ²。

三次响应 · a=3

u(δ)=δ³，则 E[G]=E[δ⁴]∝f⁻²。

与残差无关

若 u 不随训练残差变化，期望 gap 为 0，即使 Var(δ)>0。

3. n-gram 模块为什么会 overfit

§1 把 gap 拆成「采样波动」与「learned response」两项，但单臂数据无法把它们分开。nogram 对照臂让这个分离变成实测：它与 input 臂共享 backbone、数据顺序、seed、step 与分桶定义，唯一差别是没有 n-gram 表。于是有一个无近似的配对恒等式：

\[ \underbrace{G^{\text{arm}}(f)-G^{\text{ctrl}}(f)}_{\text{表的净效应}} =\underbrace{\left[L^{\text{ctrl}}_{\text{train}}(f)-L^{\text{arm}}_{\text{train}}(f)\right]}_{M(f)\;\text{记忆增益}} +\underbrace{\left[L^{\text{arm}}_{\text{val}}(f)-L^{\text{ctrl}}_{\text{val}}(f)\right]}_{X(f)\;\text{泛化代价}}. \]
纯代数改写，不含任何分布假设。共享 backbone 在差分中抵消，剩下的就是 §1 里 δᵀu_D 那一项在频率轴上的分布。

第一个结论来自左图，而且它很强：对照臂的 gap 与 f 无关。backbone 单独不产生任何频率依赖的 gap —— 这正是 §2 第四格「响应与训练残差无关 ⇒ 期望 gap 为 0」的实证（实测 0.13–0.37 而非 0，是 exposure 与有限 batch 的常数底噪）。因此频率–gap 曲线的全部结构都由 n-gram 表产生，不是 backbone 的性质。

3.1 f=1 桶上有一个精确闭合点

命中数恰为 1 的 context，其经验条件分布是单点质量，所以 H(p̂_c)=0 精确成立。由 L_train=H(p̂)+\mathrm{KL}(p̂\,\|\,q) 得

\[ f=1:\qquad \mathrm{KL}\!\left(\hat p_c\,\|\,q_c\right)=L_{\text{train}}(1)\quad\text{（无需任何近似或平滑假设）}. \]
这是全曲线上唯一一处「训练损失 = 模型对经验分布的拟合残差」严格相等的位置，因此是最干净的记忆度量。

4. 指数由响应形状决定，不是由采样律决定

§2 给出标度关系 E[G]∝f^{−(a+1)/2}，其中 a 是 learned response 的齐次指数（u(λδ)≈λᵃu(δ)）。把它反解，就得到一个可以直接从任何频率–gap 拟合里读出的量：

\[ \alpha=-\frac{a+1}{2}\quad\Longleftrightarrow\quad a=-2\alpha-1 . \]
α 是双对数斜率。a=1（线性响应）↔ α=−1，即方差律；a=0（符号／饱和响应）↔ α=−1/2。

于是「斜率为什么不是 −1」变成一个可测的问题：只要改 table optimizer，就改变了表对残差的响应形状，因此应当改变 α。注册表里的 M3／M4 已经跑过这批臂，且都带 freq-bin 记录。

三件事同时成立：

一、SGD 臂没有幂律可言。它的 gap 只有 0.026–0.039 nats（比其他臂低两个数量级），R² 掉到 0.52／0.05。所以正确的表述不是「SGD 把指数推向 −1」，而是不做 per-coordinate 归一化时，低频表行几乎没被写入，频率结构根本没有形成。这否证了「线性响应 ⇒ 观测到 −1」的天真预期：在真 harness 上，线性响应对应的是没有记忆，不是陡幂律。

二、三个归一化型优化器都给出稳定幂律，且 a 全部落在 0 附近（−0.19…+0.46），没有任何一臂接近 a=1。这正是 §2「符号／饱和响应」那一格：RMSProp（β₁=0）与 Adam 把更新除以梯度二阶矩，Δw≈−\eta\,\mathrm{sign}(g)，更新幅度与梯度大小几乎无关。命中一次和命中一千次的单步写入强度相同，低频行因此被同等强度地写满 —— 这既解释了 a≈0（故 α≈−1/2），也解释了 §3 的低频净损失。

三、方差律要求的 a=1 在本项目任何一个 run 里都没有出现，所以「充分采样区斜率应为 −1」在这份数据上不是「尚未观测到」，而是与所用优化器不相容。

4.1 词表与支撑在这里的正确位置

常见的错误是把 resolved 公式里的 K 直接取成词表大小。V=8192 时它在 f=1 处预测

\[ \frac{K-1}{f}\bigg|_{K=V,\,f=1}=8191\ \text{nats},\qquad\text{实测}\ 11.535\ \text{nats}. \]
差三个数量级。而 resolved 渐近本身要求 f ≫ K：取 K=V 就需要 f ≫ 8192，而本语料最大有界桶的几何中点只有 7071。

所以词表大小的作用不是给出指数，而是划定 resolved 区的入口：整条实测曲线都在 f < K 的未解析区，那里的形状由「表如何写入」（§4 的 a）而不是「多项式采样方差」决定。把 K 换成实测有效支撑 exp(L_train)=1.33 也救不回来 —— 它给 0.33 nats，低一个半数量级。两个方向都错，说明失配不在 K 的取值，而在机制。

需要你拍板的实验规划

上表的判决力被两个已知缺陷限制：(i) RMSProp 臂同时带 table_lr_scale=2.0，与 SGD／AdamW 的 1.0 不同，optimizer 与 LR 混淆；(ii) 这批是历史 bf16+compile、旧 warmup/warmdown schedule、单 seed。所以「a≈0」目前只能算强指示，不是定论。三个单变量实验可以补齐，全部沿用 v5 极简契约（--lr 0.0006 --lr_schedule warmup_constant --warmup_steps 100 --table_lr_scale 2.0、bf16、no-compile、clean 单表 R=2^20、freq=10、1000 步）：

  • X1 · optimizer × 响应指数（最高优先，判决 §4）：table_optimizer ∈ {rmsprop(0,0.99), adamw(0.8,0.95), sgd(m=0)}，三臂统一 table_lr_scale=2.0 解除混淆，各配一个 nogram 对照臂做双差分，seed 42/43/44。判据：a 是否随归一化强度单调、是否稳定在 0 附近、SGD 是否仍无幂律。9+3 个 run。
  • X2 · 私有自由度剂量（判决 §3.2）：只改表行维度 d ∈ {768,192,48,12}，R 与其余全部不动。预测：M(f=1) 单调下降、X/M 杠杆比下降、novel 桶的 +10.1 nats 污染随 d 缩小。这是唯一能把 d 从相关变成因果的实验，也是唯一需要偏离极简 setting 的一项（d=n_embd 是绑定项，按 P5 需你同意）。4 个 run。
  • X3 · 语料侧支撑测量（零 GPU，CPU 即可）：从 tokenized shard 统计每个 context 的命中数 f 与不同后继个数 r，得到 r̄(f)。它把「有效支撑」从 exp(L_train) 这个代理变成直接计数，并给出 H(p̂) 的桶级真值，从而把 §3 的 M/X 分解进一步拆成「统计必然」与「模型选择」两部分。不占卡、不改 setting。

建议顺序：X3（无成本，先做）→ X1（判决性）→ X2（需拍板）。三项都还没有 run_id，未登记进 docs/experiment-log.md，因此本页只以「提案」身份出现。

6. 这些实验为什么不能混在一起

  • L3/L6：固定真实分布，枚举或重复抽取训练数据集，直接匹配数学期望 E_D[G]。
  • M2/N1：固定一份自然 corpus，把不同 context 按观测频率分桶；support、长尾、碰撞、transfer 和 exposure 都随桶变化。
  • 模型 seed ≠ 数据重抽样：换 seed 测的是优化/初始化稳定性，不能估计采样残差与 learned logit 的数据协方差。
  • table-size 与 frequency 是不同轴：前者主要改变 collision/memory channel，不能拿其正斜率支持或反驳 f⁻¹。
  • 有限 validation 也有测量噪声：若 p̂_val=p+η，观测量是 G_obs=(δ−η)ᵀz_D；独立 η 不改变期望，但增加 O(m⁻¹ᐟ²) 波动。

即使每个固定 context 都处在线性响应区，条件均值也只是

\[ \mathbb{E}[G_c\mid p_c,f]\approx\frac{A_c}{f},\qquad A_c=\operatorname{tr}\!\left(J_c[\operatorname{diag}(p_c)-p_cp_c^{\mathsf T}]\right). \]

自然语料按 observed f 分桶时，p_c、support 和响应 Jacobian J_c 的组成会随 f 改变，所以实际是 E[A_c|f]/f；分布相关系数若随 f 漂移，log–log 斜率自然不等于 −1。

\[ \operatorname{SD}_{\!1\mathrm{st}}(B) \approx\sqrt{\sum_{c\in B}\frac{w_c^2B_c}{f_c}},\qquad B_c=\operatorname{Var}_{Y\sim p_c}[z_c^{\star}(Y)]. \]
所以桶内有效 context 数、权重集中度与 context 组成也会决定单个固定 corpus 上的一阶噪声是否压过系统性的 1/f 均值。

加入 replay / optimizer dynamics 后，最小动态扩展可以写成

\[ \mathbb{E}[G_c(f,E)]\approx\frac{\bar A_c(f)}{f}\,\rho_c(E,f). \]
Ā 汇总条件分布、support、hash/transfer 结构；ρ 是模型对训练残差的拟合比例，依赖 exposure E、优化器和频率。若未饱和区 ρ∝fγ，局部斜率是 γ−1+d log Ā/d log f，而不是自动等于 −1。该式是待测框架，不是现有自然语料数据已经拟合出的定律。

7. 目前允许写的最强结论

可以写：单数据集的 loss gap 精确等于 sampling residual 与 learned logits 的内积；跨随机训练集的期望是 residual–response covariance。resolved、有限支撑、线性响应的 count table 以协方差项为首阶，因此渐近出现 (K−1)/f。 配对双差分给出无假设的分解 G^arm−G^ctrl = M(f)+X(f)；nogram 对照臂的 gap 与 f 无关（0.13–0.37 nats），故频率结构全部来自表。f=1 桶上 H(p̂)=0 精确成立，因此 L_train 就是 KL(p̂‖q)：input 0.283 vs nogram 2.833，杠杆比 X/M∈[3.24,5.28]。碰撞使 novel 桶被污染 +10.106（bigram）／+5.965（trigram）nats，并使 trigram 在 f≳60 后 M<0。归一化型 optimizer 反解 a∈[−0.19,+0.46]，SGD 臂无可辨识幂律。
