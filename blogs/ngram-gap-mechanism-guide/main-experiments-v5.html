n-gram Gap：主实验与机制证据

这是一份只保留当前核心证据的主实验文档：先比较历史 2× 与当前 128× 标准，再看 exact frequency，随后给出 table-size / epoch-length / dose 三轴的定量描述，最后用 LR/β₂ 附录与 causal intervention 检查机制。旧版背景、debug 和历史架构不在本页混写。

当前结论边界：v5 标准已固定为 table LR scale 128×（实际 table lr = 0.0768），但 2× 结果仍作为同一 v5 clean measurement contract 下的历史对照保留。所有正文 gap 都是同一 logged step 的 fixed validation loss − current-batch online train loss；曲线中的散点是原始记录，细线仅为 3 点视觉连接，不是额外平滑数据。

展开 jargon 对照

2× / 128× 是 n-gram table learning-rate scale，不是 backbone LR；v5 是当前 clean-table、current-batch online、warmup-constant 的实验波次名；M2 是注入点消融；S1 是 scaling 线；_fixed 表示权威修正后结果目录。历史 2× 不是当前推荐 setting。

1. 主要现象：2× 与 128× 的注入点对照

四臂只改变 n-gram residual 的注入位置：input 加在 wte，y 直接进入 residual stream，v 先经过 attention 的 value 混合，nogram 是负对照。这里先看 2× 历史 v5 和 128× 当前标准的完整 train/val/gap 轨迹，再看末端差异。

主现象：128× 并没有让 input 主线的最终 gap 消失；它改变了不同注入路径的相对强度，尤其把 value 路径推到最高。因而“gap 存在”与“注入点决定强度”应分开陈述，不能把 2× 时代的排序直接沿用到 128×。

3.2 Epoch-length：相对完整 L4 的倍数

图 7 · 3-epoch epoch-length 阵列trigram-only；横轴是 L4 倍数，L4=337 device batches

复查后，这条轴必须拆成两段读。≤1×L4 是真正的 epoch-length 变量（shard-1 嵌套前缀、3 个 pass 对齐）：gap 随 L 温和下降，从 0.125×L4 的 3.55 降到 1×L4 的 2.47。>1×L4 的点不是更长的数据集：12 个 run 共用同一份 shard-1 频率索引（同一 freq_index_sha256），1.25–2×L4 的“一个 epoch”是 shard 1 的 wrap-around 重放，因此这些点实际落在 pass 数轴上——2×L4 的 3-epoch 终点（step 2022，gap 5.582）与 10-epoch 长 replay 的同步同 pass 点（5.609）几乎重合。旧的“U 形 + 顶点 0.41×L4”二次拟合把两个变量混进一条轴，已作废。

图 7b · gap–epoch 编号与每 epoch 增量L4 长 replay；原始 epoch-boundary 记录，不平滑

同一 L4（337 device batches/epoch）的 10-epoch trigram-only 长训中，epoch-boundary gap 为 −0.048、1.018、2.473、3.697、4.614、5.609、6.439、7.144、7.847、8.675（epoch 1–10；s1v5_128_ep_tri_1xL4_10ep，seed 42，step 3370）。从 epoch 2 到 10 的线性参考斜率约为 0.96 gap/epoch，但每 epoch 增量从 1.45 的早期峰值逐步降到约 0.7–0.8；因此当前证据支持“近似线性、斜率逐渐变小”的凹增长，而不是已经观测到明确平台。no-gram 对照在同一窗口只从约 0 增至 0.48。图中点是原始 boundary records，没有 21-step 平滑或插值。

图 7c · pass 数折叠长 replay、>1×L4 wrap 点、dose 轴放到同一“完成 pass 数”横轴

把三族 run 的横轴统一改为“训练集完成 pass 数”后：trigram-only 长 replay（红）与 >1×L4 wrap 点（橙）基本落在同一条曲线上；input 双表 128× dose 轴（蓝）也大致贴合——dose 6× 在 2000 步恰好不足 1 个 pass（2000/(337×6)=0.99），gap 正好在此穿零；0.75× 的 7.9-pass 点（7.21）与 replay 的 8-pass 点（7.14）几乎重合。0.25× 的 23.7-pass 点（10.90）低于 pass 2–10 段的线性外推，说明高 pass 端的凹弯继续发展。dose 轴的 log–log 描述斜率因此主要是 pass 数关系的重参数化，不是独立的机制幂律。

3.3 Shard dose：同一 input 主线的剂量轴

图 8 · dose–gap 关系128× · step 2000 · 11 个非 1× dose，1× 由 M2 主线提供

128× 批（nglab*_input_v5_128x_freq10）final gap 从 0.25× 的 10.895 降至 8× 的 −0.055；正 gap 点（≤5×，n=10）的 log–log 描述斜率为 −1.176，R²=.899。5× 与 6× 之间发生符号变化，因此不报告跨越零点的全局 power law。勘误：此前引用的斜率 −1.727 来自另一批 nglab*_input_v5_freq10（config 实测 table_lr_scale=2.0，2× 时代），不是 128× 标准；该批保留为历史对照（0.25× gap 11.536）。

三轴的统一读法：dose 轴大体是 pass 数轴的重参数化（图 7c）；epoch-length 轴 ≤1×L4 段与 table-size 轴则共享“碰撞稀释”结构（K∝L 或 R 变化都改变每行的干涉流量），见 §6。

5. Causal intervention：表内容、映射与低频贡献

所有 causal run 都使用 input、128×、1000 steps；边界是完整 shard 的 epoch boundary，曲线同时报告当前 batch 的 online train loss、fixed validation loss 与 gap。机制证据只采用两类干净干预：hash_reseed（只换 context→row 映射）与互补的 mask_low/high（按训练集静态频率屏蔽 residual）；freeze_table / freeze_backbone 只作为写入路径参考。两种过强的早期干预已从当前代码、登记和图表中删除。

6. 工作假说：碰撞稀释的逐 context 记忆 × backbone 读出放大

状态：假设（待挑战）。本节把三轴与干预统一到一个可计算的模型上；已闭合的部分给出数值检验，未闭合的部分列入挑战清单。所有输入均来自已登记 run 与 data/freq_index.npz（shard-1 exact counts），脚本为 docs/plot_scripts/plot_v5_theory_alpha_collapse.py 与 plot_v5_interference_model.py。
Gap(R, passes, t) ≈ A(t, passes) · Σ_c m_c · κ(f_c) · s_c(R)，   s_c(R) = f_c / (f_c + T/R)

三个因子：① m_c 是 context c 的 token 质量份额（真实计数直方图）；② κ(f) 是逐 context 记忆核，经验上取频率轴测得的 f^−β（bigram β=.253 / trigram β=.318）；③ s_c(R) 是 hash 碰撞下的写入份额稀释——RMSProp 无动量时每次命中的更新步长近似相等，一行收敛到共享该行的各 context 残差的流量加权平均，context c 保留份额 f_c/(f_c+T/R)（T 为该 branch 总流量），这一形式是推导而非拟合。④ 前置因子 A 是 backbone 读出放大：pass 1 恒为零（online 语义下首次见样本无记忆收益），随重复训练增长、终受 wd 约束。

图 14 · 干涉稀释模型 vs 实测 table-size 轴核 β 取自频率轴实测；每 branch 只有一个自由幅度参数

已闭合的检验：把频率轴的 β 与真实计数直方图代入上式做数值卷积，预测 table-size 拟合窗口斜率 bigram 0.567 / trigram 0.648（实测 0.576 / 0.665），并同时复现大 R 饱和弯头的位置与 trigram 全程 4 个量级的曲线形状——即频率指数与表大小指数确有确定关系，但它是“β + 真实 n(f) + 碰撞份额”的卷积结果，不是干净的代数幂律。

图 15 · 真实 context Zipf 结构data/freq_index.npz · rank–frequency 与 table-size 拟合窗口

被证伪的朴素版：理想 Zipf（q_r∝r^−α）下模型可解析出 γ = 1 − α(1−β)。用实测局部 α（bigram 0.99 / trigram 0.84，拟合窗口同 table-size 轴）代入得 γ=0.26/0.43，远低于实测 0.58/0.66——闭合所需 α 为 0.57/0.49。真实 n-gram 计数分布有明显曲率（不同窗口 α 从 0.67 漂到 1.28），因此代数幂律版不成立，只有数值卷积版成立；这也解释了为什么双对数“线性”只出现在中段。

模型对既有事实的覆盖：pass 数是主状态变量（图 7c 折叠、dose 6× 恰在 1 pass 穿零）；gap 密度 ∝ m(f)·κ(f)·s(f) 在低频端富集（mask_low/high 与阈值扫描方向一致）；hash_reseed 破坏 content–mapping 对齐即压制 gap；5-gram / MLP backbone 仍出现 gap（机制只需要稀疏查表 + 共享读出，不需要 attention）。

挑战清单（下一步要打的靶）： ① κ(f)∝f^−β 的微观起源未推导：采样方差论给 1/f、CLT 论给 f^−1/2，都比实测 β≈1/4、1/3 陡；候选解释是“小 f 端受条件熵 H_c 截断、大 f 端趋向 (S−1)/f”的交叉区混合，可用按 H_c 分层与超大 f 端局部斜率检验。 ② 静态份额 ≠ 动态 mask 结果：卷积预测 trigram f≤8 只占 gap 约 25%，而 mask_low f≤8 动态实验去掉约 74%（2.945→0.765，2× 批）——mask 后的再平衡 / backbone scar 不可忽略。 ③ A(t,passes) 只有形状约束、没有动力学推导；freeze_table（3.452 > control 2.724）与 mask_high t=1 残留 1.927 都说明 backbone 侧存在共适应/伤痕项。 ④ 份额取 share¹ 是 RMSProp 等步长的自然结果，但 share² 未被排除。 ⑤ β 疑似依赖 regime（2× 时代的旧描述拟合更陡），需要同一诊断在 2× 与 128× 上重测。

可证伪预测：(a) 把 3 个 pass 的数据全局混匀（打破 epoch 分块，保持每 context 总命中数）后，终点 gap 与分块 replay 相同、epoch 齿消失；(b) 换 R 会系统改变频率轴局部 β（小 R 更平）；(c) 增大 backbone wd 会压低高 pass 端的 gap 走廊；(d) 5-gram/MLP 的 (β,γ) 也应由各自计数直方图卷积闭合。
