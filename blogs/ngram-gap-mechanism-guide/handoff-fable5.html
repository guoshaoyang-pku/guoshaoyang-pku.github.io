n-gram Gap：项目现状、证据边界与理论问题

这份文档是给强模型 reviewer 的统一上下文。目标不是让 reviewer 再跑实验，而是让它在不混用历史数据、不把描述性拟合升级为定律的前提下，审计当前证据并提出一个能解释频率、表大小、epoch 暴露和干预结果的数学模型。

本 handoff 的执行边界：暂不继续启动实验。请先 review 现有代码、setting、权威 run 产物和报告；如果需要新实验，只提出最小的可辨识性实验，不要自行启动。2026-08-30 的 mask_high 新阈值批仍有部分远端 run 在排队/运行，相关结论必须标为 pending。

0. 先给 reviewer 的任务

  1. 审计“加 n-gram 后出现明显 train/validation gap”在当前 vanilla nanoGPT 协议内是否成立，以及 claim 的准确范围。
  2. 审计频率轴、clean table-size 轴、epoch-length / epoch-number 轴和 dose 轴是否真的测量了各自声称的变量，尤其检查 train loss 是否为当前 batch 的 online loss。
  3. 解释为什么频率关系和 table-size 关系在有限区间近似幂律，但低端落到 no-gram floor、高端出现饱和或弯曲。
  4. 统一解释 epoch 边界的增长、每 epoch 增量逐渐变小、shard dose 稀释，以及 hash reseed / mask-by-frequency / freeze-table / freeze-backbone 的方向。
  5. 区分已被数据支持的现象、仅有描述性拟合的现象、历史/代理证据和目前无法辨识的参数；给出一个比现有 heuristic 更好的数学模型，或明确证明为什么目前不能得到唯一模型。

Epoch length 轴：12 个 trigram-only run，每个完成 3 个 epoch，epoch_batches/L4=42…674 / 337。2026-08-30 勘误：这条轴必须拆开读。≤1×L4 是真正的 epoch-length 变量（shard-1 嵌套前缀）：gap 随 L 从 0.125× 的 3.552 温和降到 1×L4 的 2.469。>1×L4 的点共用同一份 shard-1 频率索引，其“一个 epoch”是 shard 1 的 wrap-around 重放，因此实际是 pass 数点——2×L4 的 3-epoch 终点（step 2022，gap 5.582）与 10-epoch 长 replay 的同 pass 值 5.609 几乎重合。旧的“U 形 + 二次拟合顶点 0.41×L4”把两个变量混进一条轴，已作废。

7. 现有数学模型：已经知道什么，以及为什么还不够

7.1 已经成立的最小恒等式

固定一个 context，令真实条件分布为 p，训练经验分布为 p̂，模型学到的 logits 为 z_D，采样残差为 δ=p̂−p。同一个已学模型在 population/validation 与 training empirical distribution 上的交叉熵差，可以写成 residual 与 learned response 的内积：

CE(p, q_D) − CE(p̂, q_D) = δᵀ log q_D
z_D = z₀ + Aδ + ½B[δ,δ] + …

这说明 signed mean gap 不是简单等于“采样方差”；它取决于模型如何响应训练残差。在线单数据集 gap 还会叠加 finite validation noise、context mixture、hash aliasing 和 backbone shared representation。

7.2 已有解析结果的适用范围

  • resolved finite-support count table、平滑且有效输出满足 fP(y)≫1 时，E[G(f)] = (K−1)/f + O(f⁻²)；这是 count-table 渐近，不是 Transformer 的验收定律。
  • 若 learned response 近似有幅度标度 u(λδ)∝λ^a u(δ)，则典型 gap 标度为 f^{−(a+1)/2}。归一化型 optimizer 的启发式是 a≈0，因此得到约 f^−1/2，但当前自然语料的观测 −0.253/−0.318 仍受 support、collision、exposure 和 aggregation 影响。
  • 现有两因素 heuristic G(E,f)=A f^(−β)[1−exp(−c f^γ)] 能表达低频/高频 crossover，但 S1 只支持有限窗口内 β 的相对稳定；A,c,γ 在当前覆盖下不可辨识。
  • table-size 的 clean 结果要求另一个模块显式关闭。中间区 G−G_floor∝R^α 的 α≈0.58/0.66 可能混合了可用 row 数、collision/aliasing、表写入响应和 backbone interaction；不能直接从 count-table 的 K/f 式子推出。

7.3 reviewer 必须解决的统一模型问题

请尝试构造或严格否定一个最小模型，使以下现象能够在同一套变量中出现，而不是为每张图单独拟合一个幂律：

  1. f 轴：bigram/trigram 的局部负斜率不同，低频贡献更强，novel 与 seen 不能混作同一 gap。
  2. R 轴：低 R 落到 no-gram floor，中间窗口近似 R^0.58/R^0.66，高 R 逐渐饱和；bigram 和 trigram 的 context support 不同。
  3. E 轴：≤1×L4 段 gap 随 epoch length 温和下降；>1×L4 点实为 wrap-around pass 数点；固定 L4 replay 时 gap 随 pass 数凹增长、每 pass 增量下降。
  4. D 轴：固定 step 下更大 shard dose 稀释 replay exposure，gap 穿过 near-zero floor。
  5. 干预：保留表内容但 reseed 映射会破坏 gap；mask 低频会显著消除 gap；freeze table/backbone 改变 train/val 轨迹但不等价。
  6. 优化器：per-coordinate normalization、table LR scale 与 β₂ 改变写入速度和 transient，而不是只改变一个静态 noise variance。

理想输出应明确给出：状态变量、可辨识参数、每个渐近区的假设、floor 与 saturation 的来源、为什么指数不是唯一固定分数，以及哪些现有数据足以证伪该模型。

2026-08-30 起点：主报告 §6 已给出第一个候选（碰撞稀释卷积 × backbone 放大）：用频率轴 β 与真实计数直方图数值卷积可复现 table-size 轴斜率与饱和弯头（0.567/0.648 vs 实测 0.576/0.665），纯代数版 γ=1−α(1−β) 已被实测 Zipf 结构证伪。挑战清单见该节；请优先攻击 κ(f) 的微观起源与 A(t,passes) 动力学。

  1. Verdict：按 claim 给出 supported / local-only / descriptive-only / unsupported / unrun。
