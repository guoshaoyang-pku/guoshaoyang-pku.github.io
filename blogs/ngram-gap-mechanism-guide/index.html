n-gram Gap 机制指南

本文档解释 n-gram value memory 导致的 replay-specific train/val gap：在 vanilla nanoGPT 上加一个可训练的 n-gram value table，用小数据集固定顺序多 epoch replay 训练时，为什么 train loss 下降而 val loss 翘起。

术语表

术语定义
n-gram value table / VE一张大型查找表，用几个连续 token 的 hash 做 key 查 value 向量。本文档涉及 bigram（2-gram）和 trigram（3-gram）。
gate（门控）控制 n-gram value 注入强度的机制：2×sigmoid(Linear(x))，范围 [0, 2]。初始化为 1.0（中性）。仅 v/y 注入用到；input 注入无 gate。
注入点n-gram value 加入模型的位置。本文档核心变量：v（attention 之前加到 V）、y（attention 之后加到输出）、input（加到 wte，over-encoding）。
gap / gap onsettrain loss 下降同时 val loss 上升的现象。"gap onset" 指 gap 开始出现的训练步数。
hit / hit count某个 n-gram context 在整个训练集中出现的次数。是数据的静态属性。
novel / novel buckettrain 中从未出现过的 context（hit count = 0）。是 val 翘起的主要来源。
RMSProp（table optimizer）用于 n-gram table 的优化器。无 momentum（β₁=0），β₂=0.999 使二阶矩跨 epoch 持久化。与 AdamW 的关键区别：写入方向 = 当前梯度，不被历史 momentum 稀释。
over-encodingn-gram value 加到 input embedding（wte 输出）的注入方式。是 Engram/SCONE/Over-Tokenized 等主流文献的做法。
epoch boundary训练数据遍历完一轮的分界步数。当前数据集：epoch 1→2 在 step 337，epoch 2→3 在 step 686。

1. 现象定义

在含可训练 n-gram value table 的 vanilla nanoGPT 中，小训练集（1 shard ≈ 5M tokens）、固定顺序、多 epoch replay 时：

  • train loss 阶梯下降：epoch 边界（step 337, 686）出现 cliff。
  • val loss 翘起：epoch 2-3 开始上升，与 train 分叉。
  • gap = val_loss - train_loss 随 epoch 增大。
核心结论：gap 仅依赖 n-gram value memory + 固定顺序 replay，不需要 current shell / Muon / RoPE / RMSNorm / untied embedding。vanilla nanoGPT + bigram+trigram + 合适的注入点即可复现。

2. 三种注入点（核心消融）

n-gram value table 查出的 value 向量加入模型的位置，是决定 gap 能否产生的唯一关键变量。

2.1 注入点对比

注入点技术方案公式走 attention？信号强度
vResFormer value residualV' = V + gate·ngram_ve✅ 是（被 softmax 混合）弱（norm 仅 V 的 6.5%）
yResFormer y-varianty' = attn(Q,K,V) + gate·ngram_ve❌ 否中（每层注入）
inputover-encoding（主流）x' = wte(idx) + Σ ngram_ve❌ 否中（一次注入，所有层 table 求和）

2.2 伪代码

# === input 注入（over-encoding，主流做法）===
def forward_input(idx):
    x = wte(idx) + wpe(pos)
    # n-gram value 直接加到 input embedding，不走 attention，无 gate
    x = x + compute_ngram_residual(idx)  # Σ 所有启用层的 bigram/trigram value
    x = dropout(x)
    for block in transformer.h:
        x = block(x)          # 正常 transformer block，无 n-gram 干预
    return lm_head(ln_f(x))

# === v 注入（ResFormer，加到 V，attention 之前）===
def forward_v(idx):
    x = wte(idx) + wpe(pos)
    for block in transformer.h:
        q, k, v = c_attn(ln_1(x)).split(3*dim)
        v_heads = v.view(B, T, n_head, head_dim)
        # n-gram value 加到 V，经过 gate，然后被 attention 混合
        v_heads = v_heads + gate * ngram_ve     # ← 注入点
        y = attention(q, k, v_heads)            # n-gram 信号被 softmax 混合
        x = x + c_proj(y)
        x = x + mlp(ln_2(x))
    return lm_head(ln_f(x))

# === y 注入（ResFormer y-variant，加到 attention 输出之后）===
def forward_y(idx):
    x = wte(idx) + wpe(pos)
    for block in transformer.h:
        q, k, v = c_attn(ln_1(x)).split(3*dim)
        y = attention(q, k, v)                  # 正常 attention，不混合 n-gram
        # n-gram value 加到 attention 输出，经过 gate，不 mixed
        y = y + gate * ngram_ve                  # ← 注入点
        x = x + c_proj(y)
        x = x + mlp(ln_2(x))
    return lm_head(ln_f(x))

2.3 为什么 v 注入信号弱？

n-gram value 加到 V 之后，要经过 y = softmax(QK^T/√d) · V'。attention 对 V 是线性的：

y = A · (V + G) = A·V + A·G    （A = attention matrix, G = gated n-gram value）

但 A·G ≠ G（A 的行和 = 1 但非对角项 ≠ 0），n-gram 信号被混合到所有位置。实测 n-gram value norm 只有 V 的 6.5%，信号被 V 淹没。

而 y/input 注入不经过 attention 矩阵乘法，n-gram 信号纯 per-position，不泄漏到其他位置。

3.1 关键观察

  1. y 注入 gap 最大（3.50）：信号直接到输出，不被 attention 混合，每层独立注入。
  2. input 注入 gap 中等（0.79）：over-encoding 主流做法，一次注入所有层 table 求和。
  3. v 注入 gap 最弱（0.33）：信号被 V 淹没（norm 仅 6.5%），gap 延迟到 epoch3 才明显。
  4. 无 n-gram 无 gap（0.03，旧实验）：gap 完全由 n-gram table 贡献。
  5. 相对顺序一致：y > input > v > 无 n-gram。绝对数值与旧 OPHIS 实验略有差异（LR schedule 不同），但现象完全可复现。

5. 频率 bin 分解

将 n-gram context 按 train 中的 hit count 分桶，统计每桶的 loss。这是定位 gap 来源的关键分析。

  • novel（hit=0）：val 翘起的主要来源（trigram novel 占 val ~30%）。
  • 低频（1-5 次）：gap 最大的桶——train 中见过几次，模型 memorize 了特定后续 token。
  • 高频（5k+）：gap 贡献 ≈ 0——多为 QA pattern，train/val 都能预测。

5.2 命中频次分布

train vs val 的 n-gram context 频次分布（bar = 占比，虚线 = 累积分布）。trigram val 的 novel 桶（train 中从未出现）占 ~30%，是 val 翘起的主要结构性原因。

机制解读：训练集频次呈幂律分布。低频/novel context 在 train 中被 n-gram table memorize（train loss 坍塌）， 但 val 中即使遇到相同 context，后续 token 也不同，模型"过度自信"反而出错（val loss 翘起）。 高频 context 多为可预测的 QA pattern，train/val 都能预测，对 gap 贡献最小。

7. 结论

  1. gap 的最小充分条件：vanilla nanoGPT + bigram/trigram n-gram value table + 固定顺序多 epoch replay + 合适注入点（input 或 y）。
  2. v 注入无 gap 的原因是数值尺度：n-gram value norm 仅 V 的 6.5%，信号被淹没——不是"走 attention"本身的机制问题。
  3. 只要 n-gram 信号不走 attention 混合、能有效到达输出，就能产生 gap。input 注入（over-encoding）是主流文献做法，y 注入 gap 更大但非主流。
  4. 低频 context 主导 gap：novel + 低频 bucket 是 val 翘起的主要来源；高频 bucket gap 贡献 ≈ 0。
